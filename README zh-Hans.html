更改语言

您可通过“设置管理器”更改语言（参见“设置管理器”章节）：

  1. 打开IL2_Settings_Manager.exe
  2. 从下拉菜单中选择您偏好的语言（语言以原生名称显示）
  3. 点击“应用”或“确定”
  4. 追踪器将自动以新语言重新生成所有战报和PDF报告

注意：切换语言时，所有现有的战役总结和 PDF 报告都会自动以所选语言重新生成。根据您拥有的战役数量，此过程可能需要片刻时间。

📥 安装

步骤 1：下载并安装

  1. 下载最新版本 (IL2_CampaignTracker_Setup_v2.2_ML.exe.zip)

  2. 解压该压缩包

  3. 运行解压后的IL2_CampaignTracker_Setup_v2.2_ML.exe

  4. 按照安装向导中的说明进行操作

安装向导将引导您选择安装目录并配置基本选项。

步骤 2：解压标准战役（可选但推荐）

⚠️重要提示：追踪器仅能监控位于<IL-2 BoS 路径>\data\campaigns 目录下的战役。标准 IL-2 战役并未直接存储在此文件夹中，而是通过campaigns.gtp 文件在内部运行。因此，必须先解压这些战役，才能对其进行追踪。

🚨注意：如果您修改了标准官方战役中的任务，请在将campaigns.gtp中的提取文件复制到<IL-2 BoS 路径>\data\campaigns文件夹时务必格外小心。现有文件将被覆盖，且任何自定义任务修改都将被替换为原始的默认版本。

提取标准战役的方法：

  1. 从以下链接下载unGTP-IL2：https://www.mediafire.com/file/caxpalaudz1hd47/unGTP-IL2.zip
  2. 解压并将 unGTP-IL2.exe移动至<IL-2 BoS 路径>\data
  3. 将 Campaigns.gtp拖放到 unGTP-IL2.exe上（忽略最后命令提示符窗口中的错误警告——所有内容均已解压完成）
  4. 导航至 <IL-2 BoS 路径>\data\(null)\campaigns
  5. 将所有子文件夹复制到<IL-2 BoS 路径>\data\campaigns

注意：提取官方标准战役的唯一目的是使其可在战役追踪器中使用。请勿修改官方战役。

步骤 3：运行 Tracker

从追踪器安装目录运行 IL2_Campaign_Tracker.exe。

ℹ️注意：默认情况下，当关闭《IL-2 BoS》时，Tracker 会自动退出。若要继续使用 Tracker，您必须手动重新启动它，或通过 Windows 任务计划程序设置任务，使其在 Windows 启动时自动运行。

通用设置指南请参阅此处： https://forum.il2-series.com/topic/772-expanded-career-rank-mod/#findComment-4176

🚀 首次运行设置

首次启动追踪器时，设置向导将引导您完成配置：

步骤 1：选择游戏目录

文件夹浏览器将打开。请导航至您的 IL-2 安装目录：

示例：C:\Program Files(x86)\Steam\steamapps\common\IL-2 Sturmovik Battle of Stalingrad

重要提示：请选择主游戏文件夹，而非data\Campaigns子文件夹。

步骤 2：国家验证

追踪器将扫描所有已安装的战役，并尝试为每个战役检测正确的国家。此时将出现一个验证界面，您可以在其中：

  • ✅ 确认自动检测到的国家
  • ✏️ 更正任何识别错误的战役
  • 🚫 排除一战（飞行马戏团）战役

此步骤至关重要，因为促销活动和奖项均与国家/地区相关。
ℹ️ 验证/修正国家后，这些战役数据将被写入stock_campaigns.yaml 文件。若您误选了国家，可通过手动编辑stock_campaigns.yaml 中的国家字段进行修正。

WW1（Flying Circus）检测

如果追踪器检测到“飞行马戏团”活动，您可以在本界面将其标记为WW1（忽略），这样它们就会被排除在追踪之外。

步骤 3：准备开始追踪

配置完成后，追踪器将：

  1. 解码您当前的战役存档文件
  2. 生成初始事件（现有晋升/奖项）
  3. 开始监控变更

🪖 一战检测与排除

“飞行马戏团”（一战）战役默认会被检测并排除，因为追踪器仅包含二战的军衔、奖章及战报逻辑。

检测信号包括：

  • 任务日期范围为1914–1918年
  • 战役数据中包含一战飞机关键词
  • 战役描述中包含“飞行马戏团”/一战关键词

排除机制说明：

  • 被排除的战役在解码和事件生成过程中会被跳过。
  • 排除原因存储在campaign_mission_dates.json中，以便追踪器始终忽略这些内容。
  • 您可以通过重新运行设置（删除campaign_mission_dates.json及stock_campaigns.yaml 中的相应条目），并在国家验证 GUI 中使用“一战（忽略）”复选框来查看或更改排除项。

🎖️ 晋升与奖励系统

晋升机制

晋升基于所有已完成任务的累计分数（分数值来自 campaignsstates.txt 文件，并由《IL-2 GB》内部规则计算得出）：

单次战役总分 = ∑ 任务分数
晋升分数 = 基础分数 × 军衔加权系数

排名加权系数会根据战役长度调整晋升要求（可在campaign_progress_config.yaml 中编辑）：

"1-10": 1.00 # 短战役（原版战役）
"11-20": 1.15 # 中短战役
"21-30": 1.30 # 中等战役
"31-40": 1.50 # 中长战役
"41-50": 1.75 # 长战役
"51-70": 2.00 # 超长战役
"71+": 5.50 # 史诗级战役（70+个任务）

这既能防止在长期战役中快速晋升，又能确保短期战役中的公平进度。

ℹ️示例：在 24 个任务的战役中，加权系数为 1.3，因此达到一个需要 1000 分的军衔，实际需要 1300 分（1000 x 1.30）。
当您的累计分数达到或超过 1300 分的晋升门槛时，您将晋升至下一军衔。

🚨重要提示：若修改campaign_progress_config.yaml 文件，请务必保持缩进正确（YAML 格式）。缩进不正确可能导致解析错误。

奖项机制

奖项的授予基于campaign_progress_config.yaml中定义的各项标准，并源自《IL-2 BoS》的职业模式。 所有奖项条件均为“或”条件：

标准类型 示例
累计击杀数 8 空战积分 → 一级铁十字勋章
单次任务 单次出击击落7架 → 荣誉勋章
完成的任务 15次任务 → 红星勋章
负伤 飞行员损伤值 > 20% → 负伤徽章
随机 + 阈值 高击杀数 + 运气因素 → 稀有勋章

部分奖项设有先决条件（例如：获得一级铁十字勋章前必须先获得二级铁十字勋章）及互斥关系（例如：同一任务中无法同时获得两种伤疤条纹）。

起始军衔偏移

战役可从更高军衔开始（如您所愿）。这对于那些在任务开始时飞行员已是经验丰富军官的战役非常有用。该偏移量可通过以下方式配置：

选项 1：通过设置管理器（推荐）

  1. 打开IL2_Settings_Manager.exe
  2. 转到“战役”选项卡
  3. 双击某个战役以编辑其偏移量
  4. 选择 0 到 7 之间的数值

选项 2：在campaign_mission_dates.json 中手动编辑：

"kerch": {
  "country": "Germany",
  "starting_rank_offset": 2,--> 修改此数值（0-7，默认值为0）
  "missions": {...  }
}

注意：较高的偏移值（最高 7）特别适用于拥有众多低阶军衔的英国战役，或玩家以中队队长身份开始的战役。

ℹ️注意：您可以根据个人偏好自定义晋升和奖项标准。但强烈建议在进行任何修改前，先备份原始的campaign_progress_config.yaml文件。

📊 任务简报

数据来源

任务简报数据从 IL-2的任务日志文件（.mlg文件）中提取：

位置：[IL-2 目录]\data\FlightLogs\[任务].mlg

这些二进制文件包含任务期间发生的所有事件的详细记录。 这些二进制文件由mlg2txt.exe转换为 *.txt 文件，随后进行进一步处理。

追踪内容

类别 详情
飞行时间 从起飞到降落的持续时间
击杀数 带有时间戳的空中、地面和海上目标
所受伤害 所受命中次数、来源及伤害百分比
飞行员状态 “损伤” %
状态 着陆、着陆（负伤）、硬着陆、硬着陆（负伤）、跳伞、跳伞（负伤）、阵亡/失踪

任务简报输出

每次任务都会生成两种格式的详细输出：

  1. 游戏内（飞行日志）——按时间顺序排列的事件列表，写入所有 campaigninfo.locale=*.txt文件（每个文件使用相应的语言）
  2. PDF 报告——按类别详细列出的击落统计，与游戏中的结果屏幕一致（使用您选择的语言）

注意：追踪器会将本地化内容写入战役文件夹中存在的每个语言文件。例如，如果您的战役同时包含info.locale=eng.txt和info.locale=ger.txt，则英文文件将包含英文战报，德文文件将包含德文战报。

🧹 任务清理

什么是 takeoffStatus？

IL-2 通过takeoffStatus标志来追踪任务完成情况：

数值 含义
takeoffStatus=1 任务已开始但未正常完成
takeoffStatus=2 任务已成功完成

清理界面何时出现

当检测到takeoffStatus=1的任务时，任务清理 GUI 会在追踪器启动时出现。

导致takeoffStatus=1 的常见原因：

  • ❌ 任务目标未完成
  • 🪂 飞行员跳伞逃生
  • 💀 飞行员阵亡 (KIA)
  • ❓ 飞行员失踪（MIA）
  • 💥 IL-2 在任务中坠毁
  • 🚫 强制退出（Alt+F4，任务管理器）
  • 🔌 断电 / 系统崩溃

注：并非所有takeoffStatus=1的任务都属于传统意义上的“失败”。跳伞或阵亡可能是玩家的刻意操作。清理工具会让您选择是否删除这些任务。

移除任务会发生什么

  1. 已创建备份- 在进行任何更改前保存了当前状态
  2. 任务已移除- 条目已从campaignsstates.txt中删除
  3. 弹出状态已清除- 相关事件已从campaign_popups_seen.json中移除
  4. 准备重播- 您可以再次执行该任务

保留任务会发生什么

如果您点击“全部保留”或未选择任何任务：

  • 未创建备份
  • 未进行任何更改
  • 该任务仍保留在您的存档文件中
  • 下次将再次显示清理界面（针对剩余的未完成任务）

备份仅在您通过“任务清理”工具移除未完成的任务时生成。系统不会在每次任务结束后自动创建备份。

当图形用户界面（GUI）出现时：

  • 存在多个备份，或者
  • 存在一个非当前状态的备份

当图形用户界面（GUI）未出现时：

  • 不存在备份
  • 仅存在一个备份，且该备份已是当前状态

恢复流程

  1. 从列表中选择一个备份
  2. 点击“恢复所选备份”
  3. 确认操作
  4. Tracker 将自动：
    • 创建备份文件的副本（原始备份保留）
    • 删除当前的campaignsstates.txt
    • 将备份副本重命名为campaignsstates.txt
    • 重新生成所有事件
    • 恢复匹配的弹窗状态（防止弹窗重复）

用例示例

1. 您正在“kerch”战役中执行第05号任务
2. IL-2在任务中途崩溃 → takeoffStatus=1
3. 下次Tracker启动时：清理GUI出现
4. 您选择第05号任务并点击“移除”
5. Tracker在移除任务前创建备份
6. 第05号任务从存档文件中移除
7. 您现在可以重播第05号任务

后续如需恢复：
8. 启动追踪器 → 出现“恢复”界面
9. 选择删除前的备份
10. 战役恢复至包含第05任务（未完成）的状态

📋 战役服役记录

战役服役记录是一款基于网页的应用程序，它以优雅的只读视图呈现您飞行员在所有进行中和已完成战役中的职业生涯。它以简洁、专业的格式展示您的服役历史——非常适合回顾成就或分享您的战斗记录。

⚠️重要提示：战役服役记录并非独立系统。它必须与追踪器及其关联文件配合使用，这些文件将提供所需的战役数据。

功能

  • 活动概览：浏览您参与过的所有活动，显示已完成的任务、获得的晋升和收到的奖项
  • 详细服役记录：点击任意战役可查看：
    • 包含任务简报的完整任务历史
    • 晋升与奖项的按时间顺序排列的时间轴
    • 职业统计数据（空中击落数、地面击杀数、任务成功率）
    • 飞机使用情况及性能分析
  • 飞行员档案：按战役显示并自定义飞行员姓名、照片及个人信息
  • 响应式设计：简洁现代的界面，适配任何屏幕尺寸
  • 自动生成：自动读取您的“战役追踪器”文件中的数据——无需手动输入

使用方法

  1. 在您的“活动追踪器”安装目录中找到Campaign_Service_Record.exe（参见上文“安装”部分）
  2. 双击Campaign_Service_Record.exe启动应用程序
  3. 您的默认网页浏览器将自动打开并显示您的服务记录
  4. 浏览您的活动，并点击任意活动以查看详细统计数据
  5. 如果 60 秒内无操作，服务器将自动关闭

注意：战役服役记录需要战役追踪器的数据支持。您必须至少运行一次战役追踪器并完成至少一项任务，战役信息才会显示在服役记录中。

界面概览

登录页面

  • 左侧面板：飞行员信息（照片、姓名、服役概况）
  • 右侧面板：所有已完成任务的战役列表
    • 显示每个战役的任务数量、获得的晋升和奖项
    • 点击任意活动以查看详细服务记录

战役详情页

  • 左侧栏：飞行员信息（可自定义照片及个人资料）、晋升与奖项的时间轴
  • 中间栏：职业统计数据，包括：
    • 空中及地面击杀总数
    • 任务结果
    • 飞机使用明细
    • 等
  • 右侧栏：包含详细战斗结果的任务简报
  • 返回按钮：返回战役概览

按战役设置语言：详情页可显示为与全局设置不同的语言。此项配置位于“设置管理器”的“战役”选项卡下。当某个战役设置了特定语言覆盖时，详情页（包括任务简报）将显示为该语言，而登录页仍保持您的全局语言。

自定义飞行员信息

点击飞行员照片或姓名字段进行自定义：

  • 飞行员照片：点击上传新照片（支持常见图片格式）
  • 个人信息：编辑姓名、名字、生日、出生地和出生国家
  • 所有更改均会自动保存，并在不同会话中保持

故障排除

问题：“正在加载活动...” 提示持续显示

原因：无可用活动数据或 JSON 文件为空
解决方案：

  • 请确保您已至少运行过一次战役追踪器
  • 在任意战役中完成至少一项任务
  • 请确认您的“战役追踪器”安装目录中包含以下文件：
    • campaign_completion_state.json
    • campaign_events.json
    • campaigns_decoded.json
    • campaign_mission_dates.json

问题：广告系列服务记录无法启动

原因：端口 5000 已被其他应用程序占用
解决方案：

  • 关闭所有使用 5000 端口的其他 Web 服务器或应用程序
  • 如果问题仍然存在，请重启计算机以释放该端口

问题：浏览器显示“无法连接”或“页面未找到”

原因：应用服务器启动失败
解决方案：

  • 检查安装目录中是否同时存在Campaign_Service_Record.exe和_internal文件夹
  • 确保您的杀毒软件未阻止该应用程序
  • 尝试以管理员身份运行Campaign_Service_Record.exe

问题：点击活动时显示“无法加载活动详情”

原因：活动数据缺失或损坏
解决方案：

  • 再次运行 Campaign Tracker 以重新生成 JSON 文件
  • 确保该活动至少有一个已完成的任务
  • 检查 JSON 文件中的活动名称是否一致

问题：试用照片无法上传

原因：文件格式不支持或文件过大
解决方案：

  • 请使用常见的图像格式（JPG、PNG、BMP）
  • 确保图像文件小于 5MB
  • 尝试将图片转换为 PNG 格式

问题：应用程序启动后立即关闭

原因：60 秒的空闲超时时间可能过短，或者浏览器未打开
解决方案：

  • 再次双击Campaign_Service_Record.exe
  • 手动打开浏览器并访问http://127.0.0.1:5000
  • 保持浏览器标签页处于活动状态，以防止自动关闭

问题：德语奖项和图片中未显示卐字符

原因：
Campaign Tracker 不以任何形式支持、认可或推广国家社会主义意识形态或符号。
为遵守多国法律法规并尊重社区标准，本软件默认图像中已移除卍字符及其他相关符号。

解决方案：
需要历史准确图像的用户可本地替换图片：

  • 将奖项图片替换到
    <IL-2 BoS 路径>\data\swf\CampaignRanksAwards\Germany

  • 将
    <Tracker安装目录>\_internal\static\images\background_Germany.png
    <追踪器安装文件夹>\_internal\static\images\german_flag.png

⚠️ 替换图片内容后，必须保留原始文件名和文件类型。

技术信息

  • 服务器地址：http://127.0.0.1:5000（仅限本地计算机）
  • 自动关闭：服务器在闲置 60 秒后会自动停止
  • 数据位置：从与可执行文件相同的目录中读取 JSON 文件
  • 浏览器兼容性：支持所有现代浏览器（Chrome、Firefox、Edge）
  • 网络：无需互联网连接；完全在本地机器上运行

🪖 职业服务记录

“职业生涯记录”是专为《IL-2》内置“职业生涯模式”（非“战役模式”）设计的独立网页应用。它直接从游戏自身的cp.dbSQLite 数据库中读取您的职业生涯数据——无需额外的追踪器或数据文件。该应用将展示您飞行员在所有战区的完整服役历史，包括晋升、奖项、任务等。

问题：“正在加载职位...” 提示持续显示

原因：未找到职业数据库或不存在职业 解决方案：

  • 请确保已安装《IL-2 Sturmovik: Great Battles》
  • 在启动本应用程序前，请在游戏中至少开始一个职业模式
  • 确认游戏目录设置正确（“生涯服务记录”会从 Windows 注册表中自动检测 IL-2 的安装路径）

问题：职业服务记录无法启动

原因：端口 5001 已被其他应用程序占用 解决方案：

  • 关闭所有使用5001端口的其他Web服务器或应用程序
  • 如果问题仍然存在，请重启计算机以释放该端口

问题：浏览器显示“无法连接”或“页面未找到”

原因：应用服务器启动失败 解决方案：

  • 检查安装目录中是否同时存在Career_Service_Record.exe和_internal文件夹
  • 确保您的杀毒软件未阻止该应用程序
  • 尝试以管理员身份运行Career_Service_Record.exe
  • 手动打开浏览器并访问http://127.0.0.1:5001

问题：缺少事件或任务简报

原因：任务报告文件尚未解析（首次加载） 解决方案：

  • 打开职位详情页面后请稍等片刻——首次加载时，系统会在后台解析职位详情
  • 几秒钟后重新加载页面；解析过程中将显示进度指示器

技术信息

  • 服务器地址：http://127.0.0.1:5001（仅限本地计算机）
  • 自动关闭：服务器在闲置 60 秒后将自动停止
  • 数据源：直接读取<IL-2 安装目录>\data\Career\cp.db
  • 浏览器兼容性：支持所有现代浏览器（Chrome、Firefox、Edge）
  • 网络：无需互联网连接；完全在本地机器上运行

❓ 常见问题

为什么我的自定义战役/任务无法被检测到？

答：追踪器会解析任务文件以提取日期和元数据。为确保您的自定义战役能被正确识别，请遵循以下黄金法则：

⚠️重要提示：读取任务需使用英文语言文件

追踪器仅读取英文语言文件（.eng简报文件和info.locale=eng.txt）来提取任务日期和战役信息。IL-2 会在内部存储用户的语言偏好设置，而我们无法检测您在游戏中使用的语言。因此：

  • 每个任务必须拥有对应的.eng简报文件（例如：01 .Mission 对应01. eng）
  • 您的战役文件夹中必须包含一个用于战役描述的info.locale=eng.txt文件

即使您使用其他语言进行游戏，这些英文文件也必须存在才能使追踪器正常工作。追踪器不会读取.ger、.rus、.fra或其他语言文件来提取日期。

ℹ️多语言输出

当将事件和战报写回您的战役时，追踪器会自动更新所有现有的info.locale=*.txt文件。每个文件将以对应的语言写入：

  • info.locale=eng.txt→ 英文内容
  • info.locale=ger.txt→ 德语内容 (Deutsch)
  • info.locale=fra.txt→ 法语内容 (Français)
  • info.locale=spa.txt→ 西班牙语内容 (Español)
  • info.locale=pol.txt→ 波兰语内容 (Polski)
  • info.locale=rus.txt→ 俄语内容 (Русский)
  • info.locale=chs.txt→ 中文内容（简体中文）

更多详情请参阅“支持的语言”。

任务文件命名：

  • 使用数字前缀表示任务顺序：01.Mission、02.Mission、03.Mission或1.Mission、2.Mission 等。
  • 基于日期的命名方式也适用：1943-07-04.Mission、1943-07-04a.Mission
  • 支持的扩展名：.Mission、.mission、.msnbin

任务日期检测（在.eng简报文件中）： 追踪器将按以下优先级顺序查找日期信息：

  1. 简报中的“日期”字段（例如：Date: 1943年11月4日）
  2. Time：任务开始时间字段（例如，Time: 09:45）
  3. 若文件名包含日期，则采用该格式（例如：1943-07-04.Mission）

支持的日期格式：

  • 1943年11月4日
  • 1943年11月4日（无逗号）
  • 1943年11月4日或1943年11月4日（DD.MM.YYYY 或 MM.DD.YYYY）
  • 1943-07-04（文件名中的 ISO 格式）

战役文件夹结构：

路径：IL-2 BoS\data\Campaigns\您的战役名称\
    ├── info.locale=eng.txt    （必填 - 用于读取战役描述）
    ├── info.locale=ger.txt    （可选 - 追踪器在此写入德语内容）
    ├── info.locale=fra.txt    （可选 - 追踪器在此写入法语内容）
    ├── info.locale=rus.txt    （可选 - 追踪器在此写入俄语内容）
    ├── 01.Mission             (任务文件)
    ├── 01.eng                 (必填 - 带日期/时间的英文简报)
    ├── 02.Mission
    ├── 02.eng                 (必填 - 带日期/时间的英文简报)
    └── ...

国家检测： 追踪器通过以下方式自动检测您的国家/阵营：

  1. 任务文件中的飞机名称（例如：bf109 → 德国，spitfire → 英国）
  2. 包含国家标识符的部队名称
  3. 您可以在首次运行时通过“国家验证器”GUI 手动设置/更正，或稍后在stock_campaigns.yaml中手动调整

常见问题：

  • 缺少.eng简报文件 → 无法提取日期（任务仍将作为“任务 1”、“任务 2”等进行追踪，但没有日期信息）
  • 缺少info.locale=eng.txt→ 无法获取战役描述，追踪器无法读取战役信息
  • 任务简报中的日期格式不符合标准 → 请使用上述支持的格式之一
  • 战役文件夹名称中包含特殊字符 → 请避免使用变音符或特殊符号
  • 一战战役（Flying Circus）→ 默认被排除（参见“一战检测与排除”章节）

问：我可以同时运行多个追踪器实例吗？

答：不可以。每次只能有一个实例监控您的战役。

问：追踪器会修改我的《IL-2》安装吗？

答：追踪器仅修改：

  • Campaigninfo.locale=eng.txt文件（新增“活动”部分）
  • 在 usersave 文件夹中创建备份文件

它不会修改任何游戏可执行文件或核心文件。

问：这与模组兼容吗？

A:是的，只要模组采用标准战役结构即可。自定义战役会在首次运行设置时被自动检测。

问：我可以手动编辑配置吗？

A:可以，但我们建议使用“设置管理器”（IL2_Settings_Manager.exe）进行大多数更改。它提供了一个用户友好的界面，并在需要时自动处理配置文件的再生成。

若需进行高级自定义，可手动编辑campaign_progress_config.yaml文件以：

  • 调整晋升分数阈值
  • 修改奖励标准
  • 添加自定义奖项
  • 更改军衔缩放系数

⚠️ 在手动编辑配置文件之前，请务必创建备份。

问：如何重置所有设置？

A:删除以下文件并重启追踪器：

  • campaign_mission_dates.json
  • campaign_popups_seen.json
  • campaigns_decoded.json
  • campaign_events.json

问：是否支持多人游戏？

A：本追踪器专为单人职业战役设计。多人游戏任务生成的保存数据结构与之不同。

问：为什么需要重启 IL-2 才能看到新事件？

A:IL-2 在游戏启动时会加载战役描述文件（info.locale=eng.txt），并将其缓存到内存中。追踪器所做的更改会写入该文件，但除非重启 IL-2，否则不会在游戏中显示。不过，当你获得晋升或奖项时，仍会立即看到弹出提示。

Q：如果我手动删除备份文件会怎样？

A：备份索引（campaignsstates_hash_index.json）仍会引用该文件，但“还原”界面将跳过实际备份文件缺失的备份项。

问：我可以在《Flying Circus》（一战）中使用追踪器吗？

A：默认情况下，系统会检测并排除“飞行马戏团”战役。该追踪器专为二战战役设计，不包含一战时期的军衔或奖章。您可以在国家验证步骤中控制排除项（勾选一战“忽略”复选框），但一战战役将无法获得历史准确的军衔或奖章。

问：我可以将本追踪器与 Pat Wilson 的战役生成器（PWCG）配合使用吗？

答：不可以——本追踪器既无法与PWCG配合使用，也不会对其造成干扰
