IL-2 Campaign Progress Tracker

Комплексный инструмент для отслеживания одиночных кампаний и карьерного режима в игре IL-2 Sturmovik Great Battles, посвященной Второй мировой войне. Автоматически отслеживает ваш прогресс в кампании, рассчитывает повышения по службе и награды на основе исторических критериев, генерирует подробные отчеты по миссиям, создает PDF-отчеты о карьере вашего пилота и, по желанию, генерирует главы повествовательной истории, созданные искусственным интеллектом, для каждой миссии.

Что переводится

Когда вы выбираете язык, на этом языке отображается следующий контент:

  • Всплывающие уведомления — объявления о повышении в звании и наградах
  • События в игре — раздел «События», записываемый в файлы campaign info.locale=*.txt
  • Подведение итогов миссий — бортовые журналы, отчеты о сбитых самолетах, сообщения о состоянии
  • Отчеты в формате PDF — полные отчеты о карьере, включая всю статистику
  • Служебная карточка кампании — веб-интерфейс служебной карточки
  • Менеджер настроек — все метки, кнопки и сообщения пользовательского интерфейса
  • Главы сюжета ИИ — главы сюжета генерируются на выбранном языке

Смена языка

Вы можете изменить язык с помощью диспетчера настроек (см. раздел «Диспетчер настроек» ):

  1. Откройте файл IL2_Settings_Manager.exe
  2. Выберите желаемый язык из раскрывающегося списка (языки отображаются под своими оригинальными названиями)
  3. Нажмите «Применить» или «ОК»
  4. Трекер автоматически перегенерирует все отчеты и PDF-доклады на новом языке

Примечание: при смене языка все существующие отчеты по кампаниям и отчеты в формате PDF автоматически перегенерируются на выбранном языке. Это может занять некоторое время в зависимости от количества ваших кампаний.

📥 Установка

Шаг 1: Загрузка и установка

  1. Скачайте последнюю версию (IL2_CampaignTracker_Setup_v2.2.4_ML.exe.zip)

  2. Разархивируйте файл zip

  3. Запустите извлеченный файл IL2_CampaignTracker_Setup_v2.2.4_ML.exe

  4. Следуйте инструкциям по установке в мастере установки

Мастер установки поможет вам выбрать каталог установки и настроить основные параметры.

Шаг 2: Распаковка стандартных кампаний

⚠️ ВАЖНО: Трекер может отслеживать только кампании, расположенные в <Путь к IL-2 BoS>\data\campaigns. Стандартные кампании IL-2 не хранятся непосредственно в этой папке — они запускаются внутренне из файла Campaigns.gtp. Эти кампании необходимо извлечь, прежде чем их можно будет отслеживать.

Вариант A: Через диспетчер настроек (рекомендуется)

  1. Откройте файл IL2_Settings_Manager.exe
  2. Перейдите на вкладку «Кампании»
  3. Нажмите «Импортировать стандартные кампании»
  4. Менеджер настроек автоматически извлечет кампании из файла Campaigns.gtp (и из файла Missions.gtp, если он присутствует) в папку IL-2 data\Campaigns
  5. Добавляются только новые или отсутствующие файлы кампаний — существующие файлы никогда не перезаписываются

Вариант B: Ручное извлечение

  1. Скачайте unGTP-IL2 по адресу: https://www.mediafire.com/file/caxpalaudz1hd47/unGTP-IL2.zip
  2. Разархивируйте и переместите файл unGTP-IL2.exe в <Путь к IL-2 BoS>\data
  3. Перетащите файл Campaigns.gtp на файл unGTP-IL2.exe (игнорируйте любое предупреждение об ошибке в окне командной строки в конце — все было извлечено)
  4. Перейдите в папку <Путь к IL-2 BoS>\data\(null)\campaigns
  5. Скопируйте все вложенные папки в <Путь к IL-2 BoS>\data\campaigns

🚨 ВНИМАНИЕ: Если вы изменили миссии, принадлежащие стандартной официальной кампании, используйте вариант A (Менеджер настроек), который никогда не перезаписывает существующие файлы. Ручное копирование заменит все файлы, которые вы изменили.

Примечание: Цель извлечения стандартных официальных кампаний заключается ИСКЛЮЧИТЕЛЬНО в том, чтобы сделать их доступными для Campaign Tracker. Пожалуйста, не изменяйте официальные кампании.

Шаг 3: Запустите Tracker

Запустите IL2_Campaign_Tracker.exe из каталога установки трекера.

ℹ️ ПРИМЕЧАНИЕ: По умолчанию трекер автоматически закрывается при закрытии IL-2 BoS. Чтобы продолжить использование трекера, необходимо либо перезапустить его вручную, либо настроить задачу в Планировщике заданий Windows для его автоматического запуска при запуске Windows.

Общее руководство по настройке можно найти здесь: https://forum.il2-series.com/topic/772-expanded-career-rank-mod/#findComment-4176

Удаление

  1. Запустите файл unins000.exe из папки установки Tracker

    🚨 НЕ ЗАПУСКАЙТЕ cleanup_tracker_content.exe напрямую — это вспомогательная утилита для деинсталлятора.

  2. Следуйте инструкциям по удалению в мастере

ℹ️ ПРИМЕЧАНИЕ: Все внутриигровые отчеты и события будут удалены, а исходные файлы info.locale=[язык].txt будут восстановлены в исходное состояние.

Если вы решите сохранить файлы настроек во время удаления и позже переустановите трекер в ту же папку, эти файлы не будут перезаписаны. Ваши ранее сохраненные настройки будут сохранены.

🚀 Настройка при первом запуске

При первом запуске трекера мастер настройки проведет вас через процесс настройки:

Шаг 1: Выбор каталога с игрой

Откроется окно выбора папки. Перейдите в папку установки IL-2:

Пример: C:\Program Files (x86)\Steam\steamapps\common\IL-2 Sturmovik Battle of Stalingrad

Важно: выберите главную папку игры, а НЕ подпапку data\Campaigns.

Шаг 2: Проверка страны

Трекер просканирует все установленные кампании и попытается определить правильную страну для каждой из них. Появится окно проверки, в котором вы сможете:

  • ✅ Подтвердите автоматически обнаруженные страны
  • ✏️ Исправьте неправильно идентифицированные кампании
  • 🚫 Исключить кампании Первой мировой войны (Flying Circus)

Это важно, поскольку промоакции и награды зависят от страны.
ℹ️ После проверки/исправления стран эти кампании записываются в файл stock_campaigns.yaml. Если вы случайно указали неверную страну, вы можете исправить это, вручную отредактировав страну в файле stock_campaigns.yaml.

Обнаружение WW1 (Flying Circus)

Если трекер обнаруживает кампании Flying Circus, вы можете — или, лучше сказать, должны — пометить их как WW1 (игнорировать) на этом экране, чтобы они были исключены из отслеживания.

Шаг 3: Готовность к отслеживанию

После настройки трекер:

  1. Декодирует файл сохранения текущей кампании
  2. Генерирует начальные события (существующие повышения/награды)
  3. Начинает отслеживать изменения

⚙️ Менеджер настроек

Менеджер настроек (IL2_Settings_Manager.exe) предоставляет удобный графический интерфейс для настройки всех параметров трекера без необходимости вручную редактировать конфигурационные файлы.

Открытие Менеджера настроек

  1. Найдите файл IL2_Settings_Manager.exe в папке установки трекера
  2. Дважды щелкните, чтобы открыть Менеджер настроек
  3. Внесите изменения и нажмите «Применить» или «ОК»

🎖️ Система повышений и наград

Как работает система повышений

Повышения в звании основаны на накопленном балле по всем выполненным миссиям (значение балла берется из файла campaignsstates.txt и рассчитывается по внутренним правилам IL-2 GB):

Общий балл за кампанию = ∑ баллов за миссии
Балл для повышения в звании = базовый балл × коэффициент масштабирования звания

Коэффициент масштабирования ранга корректирует требования в зависимости от длительности кампании (его можно изменить в файле campaign_progress_config.yaml):

"1-10": 1.00 # Короткие кампании (стандартные кампании)
"11-20": 1.15 # Кампании средней длины
"21-30": 1.30 # Средние кампании
"31-40": 1.50 # Средне-длинные кампании
"41-50": 1.75 # Длинные кампании
«51–70»: 2,00 # Очень длинные кампании
«71+»: 5,50 # Эпические кампании (70+ миссий)

Это предотвращает быстрое повышение в длительных кампаниях, одновременно обеспечивая справедливый прогресс в коротких.

ℹ️ Пример: в кампании из 24 миссий коэффициент масштабирования равен 1,3, поэтому для достижения звания, требующего 1000 очков, потребуется 1300 фактических очков (1000 x 1,30).
Когда ваш накопленный балл достигнет или превысит порог повышения в 1300 очков, вы будете повышены до следующего звания.

🚨 ВАЖНО: Если вы изменяете файл campaign_progress_config.yaml, будьте внимательны и соблюдайте правильную отступку (формат YAML). Неправильная отступка может привести к ошибкам синтаксического анализа.

Как работают награды

Награды присуждаются на основе различных критериев, определенных в файле campaign_progress_config.yaml, и основаны на режиме карьеры в IL-2 BoS. Все условия для получения наград являются условиями «ИЛИ »:

Тип критериев Пример
Накопленное количество убийств 8 очков в воздушных боях → Железный крест 1-й степени
Один вылет 7 сбитых самолетов за один вылет → Медаль Почета
Выполненные миссии 15 миссий → Орден Красной Звезды
Ранение в бою Повреждения пилота > 20% → Знак ранения
Случайное + пороговое Большое количество сбитых самолетов + фактор удачи → Редкие награды

Некоторые награды имеют предварительные условия (например, необходимо получить Железный крест 2-го класса перед 1-м классом) и взаимную исключительность (например, нельзя заработать оба варианта нашивки за ранение в одной миссии).

Смещение начального звания

Кампании могут начинаться с более высоких званий (если вы хотите). Это полезно для кампаний, в которых ваш пилот уже является опытным офицером в начале миссии. Смещение можно настроить:

Вариант 1: Через Менеджер настроек (рекомендуется)

  1. Откройте файл IL2_Settings_Manager.exe
  2. Перейдите на вкладку «Кампании»
  3. Дважды щелкните по кампании, чтобы изменить ее смещение
  4. Выберите значение от 0 до 7

Вариант 2: Ручное редактирование в файле campaign_mission_dates.json:

"kerch": {
  "country": "Germany",
  "starting_rank_offset": 2, --> измените это число (0-7, по умолчанию = 0)
  "missions": {...  }
}

Примечание: Более высокие значения смещения (до 7) особенно полезны для британских кампаний, в которых много низших званий, или для кампаний, где игрок начинает в роли командира эскадрильи.

ℹ️ Примечание: Вы можете настроить критерии продвижения по службе и награждения в соответствии со своими предпочтениями. Однако настоятельно рекомендуется создать резервную копию исходного файла campaign_progress_config.yaml перед внесением каких-либо изменений.

📊 Подведение итогов миссий

Источник данных

Данные подведения итогов миссии извлекаются из файлов журнала миссий IL-2 (файлы.mlg ):

Расположение: [Каталог IL-2]\data\FlightLogs\[mission].mlg

Эти двоичные файлы содержат подробные записи обо всем, что произошло во время миссии. Эти двоичные файлы «переводятся» программой mlg2txt.exe в файл *.txt, а затем подвергаются дальнейшей обработке.

Что отслеживается

Категория Подробности
Время полета Продолжительность от взлета до посадки
Уничтожения Воздушные, наземные и морские цели с отметками времени
Полученный урон Полученные попадания, от кого, процент урона
Состояние пилота «Урон» %
Статус Приземлился, Приземлился (ранен), Твердое приземление, Твердое приземление (ранен), Катапультировался, Катапультировался (ранен), Погиб в бою/Пропал без вести

Результаты разбора

Каждая миссия генерирует подробный отчет в двух форматах:

  1. В игре (Журнал полетов) — хронологический список событий, записываемый во все файлы info.locale=*.txt кампании (каждый на своем языке)
  2. Отчет в формате PDF — подробная разбивка сбитых самолетов по категориям, соответствующая экрану результатов в игре (на выбранном вами языке)

Примечание: Трекер записывает локализованный контент в каждый языковой файл, который существует в папке вашей кампании. Например, если в вашей кампании есть как info.locale=eng.txt, так и info.locale=ger.txt, английский файл будет содержать отчеты на английском языке, а немецкий файл — отчеты на немецком языке.

🧹 Очистка миссии

Что такое takeoffStatus?

IL-2 отслеживает завершение миссии с помощью флага takeoffStatus:

Значение Значение
takeoffStatus=1 Миссия начата, но не завершена должным образом
takeoffStatus=2 Миссия завершена успешно

Когда появляется графический интерфейс очистки

Графический интерфейс очистки миссии появляется при запуске трекера, когда обнаруживаются миссии с takeoffStatus=1.

Распространенные причины takeoffStatus=1:

  • ❌ Цель миссии не выполнена
  • 🪂 Пилот катапультировался
  • 💀 Пилот погиб в бою (KIA)
  • ❓ Пилот пропал без вести (MIA)
  • 💥 Ил-2 разбился во время миссии
  • 🚫 Принудительное завершение (Alt+F4, Диспетчер задач)
  • 🔌 Отключение электроэнергии / сбой системы

Примечание: не все миссии с takeoffStatus=1 являются «неудачными» в традиционном смысле. Катапультирование или гибель в бою могут быть намеренными игровыми действиями. Инструмент очистки позволяет выбрать, удалять ли эти миссии.

Что происходит при удалении миссии

  1. Резервная копия создана — текущее состояние сохранено до внесения каких-либо изменений
  2. Миссия удалена — запись удалена из файла campaignsstates.txt
  3. Состояние всплывающих окон очищено — связанные события удалены из файла campaign_popups_seen.json
  4. Готово к повторному прохождению — Вы можете пройти миссию снова

Если вы нажмете «Сохранить все» или не выберете ни одной миссии:

  • Резервная копия не создана
  • Изменений не внесены
  • Миссия остается в вашем файле сохранения
  • В следующий раз снова появится окно очистки (для оставшихся незавершенных миссий)

💾 Система резервного копирования и восстановления

Когда создаются резервные копии

Резервные копии создаются только при удалении незавершенных миссий с помощью инструмента «Очистка миссий». Они не создаются автоматически после каждой миссии.

Это позволяет восстановить кампанию до состояния, предшествовавшего удалению каких-либо миссий.

7. Теперь вы можете повторить миссию 05

📖 Генерация сюжета с помощью ИИ

Функция генерации сюжета ИИ использует большую языковую модель (LLM) для написания повествовательных глав военного дневника для каждой миссии в вашей карьере или кампании. Истории написаны в исторической прозе от третьего лица — не в стиле отчета о миссии — и сохраняют непрерывность между сессиями благодаря скользящей повествовательной памяти.

Эта функция работает как в режиме карьеры (служебная записка карьеры), так и в режиме кампании (служебная записка кампании). Главы отображаются на страницах с подробностями служебной записки рядом с вашими отчетами.

Как генерируются истории

Для режима карьеры:

Истории создаются на основе данных, полученных непосредственно из файла cp.db игры и проанализированного отчета о миссии:

  • Данные о пилоте: звание, эскадрилья, тип самолета, на котором выполнялся вылет
  • Данные о миссии: дата, время суток (вычисляется), сезон (вычисляется), результат, продолжительность полета, количество сбитых самолетов
  • Тип миссии: тактическая роль (например, «Патрулирование на передовой», «Сопровождение бомбардировщиков», «Бомбардировка моста»), полученная из файла миссии
  • Формирование: размер и роль (лидер или ведомый) — терминология Люфтваффе (Rotte/Schwarm) для немецких пилотов
  • Карьерный рост: все награды, общее количество воздушных побед, текущее звание
  • События, связанные с конкретным вылетом: награды или повышение в звании, полученные после данного вылета
  • События в эскадрилье: повышения в звании, награды, погибшие в бою/пропавшие без вести/раненые в бою, а также переводы других пилотов в вашей эскадрилье
  • Исторический контекст: соответствующий периоду фон для вашей эскадрильи, автоматически дополняемый с помощью LLM при первом столкновении
  • Другие события карьеры: периоды восстановления, переводы из эскадрильи, назначения на должности командиров, упомянутые в повествовании
  • Повышения между миссиями: повышения, произошедшие в дни, когда не было полетов, вплетены в качестве фонового контекста
  • Переходы между театрами военных действий: когда пилот переходит на новый театр военных действий, глава использует структуру из 4 абзацев, охватывающую завершение предыдущей кампании, период перевода (включая любые награды/повышения, полученные в промежуточный период), прибытие в новую часть и первый вылет

Для режима «Кампания»:

Истории используют данные кампании и подведения итогов:

  • Название кампании и вводный текст (из файла с информацией о кампании)
  • Дата миссии, время суток, сезон, результат, количество сбитых самолетов, продолжительность полета
  • Звание и награды, рассчитанные трекером
  • Тип миссии, определяемый структурой кампании

Непрерывность повествования

Каждая сессия сюжета поддерживает непрерывную память повествования, которая переносится из одной главы в другую:

  • Текущее звание и эскадрилья
  • Результаты последних миссий
  • Ключевые вехи карьеры (повышения, значимые награды)
  • Повторяющиеся темы (выживание в условиях давления, боевое лидерство и т. д.)
  • Общее количество подтвержденных воздушных побед (авторитетный подсчет из базы данных игры)
  • Ранее использовавшиеся названия глав (для избежания повторений в структуре и изображениях погоды)

Нарративная память хранится локально и используется в качестве контекста для каждой новой главы, поэтому ссылки на прошлые события, установленный оперативный контекст и развитие персонажей остаются последовательными на протяжении всей карьеры.

Управление главами

На странице сведений о службе:

  • Просмотр глав: Главы истории отображаются в хронологическом порядке наряду с вашими отчетами о миссиях
  • Удаление главы: нажмите кнопку удаления на любой главе, чтобы удалить её и записи в памяти. Номера глав перенумеруются автоматически
  • Перегенерация: после удаления нажмите «Генерировать», чтобы создать новую главу для этой миссии
  • Предварительный просмотр контекста: конечная точка API позволяет вам проверить вводные данные сюжета для любой миссии перед генерацией (/api/stories/<source>/<id>/context_preview)

Группировка глав по дате: если пилот совершил несколько вылетов в один календарный день, они автоматически объединяются в одну главу, а не записываются как отдельные записи. Количество целей по словам и абзацам масштабируется соответственно (две миссии → 3 абзаца; три и более → 4 абзаца).

Хранение данных сюжета

Главы истории и нарративная память хранятся вне каталога установки приложения, чтобы они сохранялись при переустановке:

Обогащение исторического контекста

Если в локальном файле historical_context/squadrons.json нет исторических данных о вашем эскадроне, приложение вызывает LLM для генерации точного для данного периода краткого описания и кэширует его для будущего использования. Это происходит прозрачно при первом создании истории для неизвестного эскадрона.

📋 Отчет о службе в кампании

«Служебная запись кампании » — это веб-приложение, которое предоставляет элегантный просмотр карьеры вашего пилота во всех текущих и завершенных кампаниях в режиме «только для чтения». Оно представляет вашу служебную историю в лаконичном, профессиональном формате — идеальном для просмотра достижений или публикации ваших боевых результатов.

⚠️ ВАЖНО: «Служебная история кампаний» не является автономной системой. Она работает исключительно в сочетании с трекером и связанными с ним файлами, которые предоставляют необходимые данные о кампаниях.

Особенности

  • Обзор кампаний: просматривайте все кампании, в которых вы участвовали, с указанием выполненных миссий, полученных повышений и наград
  • Подробная служебная карточка: нажмите на любую кампанию, чтобы просмотреть:
    • Полную историю миссий с отчетами
    • Хронологическую шкалу повышений и наград
    • Статистика карьеры (сбитые самолеты, уничтоженные наземные цели, процент успешных миссий)
    • Распределение использования и эксплуатационных характеристик самолетов
  • Главы истории ИИ: если настроены истории ИИ, в каждой записи о миссии рядом с отчетом отображается сгенерированная глава повествования
  • Профиль пилота: отображение и настройка имени пилота, фотографии и личной информации для каждой кампании
  • Адаптивный дизайн: лаконичный, современный интерфейс, который работает на экранах любого размера
  • Автоматическое создание: автоматическое считывание данных из файлов Campaign Tracker — ручной ввод не требуется

Как использовать

  1. Найдите файл Campaign_Service_Record.exe в каталоге установки Campaign Tracker (см. раздел «Установка» выше)
  2. Дважды щелкните Campaign_Service_Record.exe, чтобы запустить приложение
  3. Ваш браузер по умолчанию откроется автоматически и отобразит вашу служебную запись
  4. Просмотрите свои кампании и щелкните любую из них, чтобы просмотреть подробную статистику
  5. Сервер автоматически отключится через 60 секунд бездействия

Примечание: «Отчет о службе в кампании» требует данных из трекера кампаний. Вы должны запустить трекер кампаний хотя бы один раз и выполнить хотя бы одну миссию, прежде чем кампании появятся в отчете о службе.

Обзор интерфейса

Страница

  • Левая панель: информация о пилоте (фото, имя, обзор службы)
  • Правая панель: список всех кампаний с выполненными миссиями
    • Показывает количество миссий, заработанные повышения и полученные награды по каждой кампании
    • Нажмите на любую кампанию, чтобы просмотреть подробную историю работы

Страница сведений о кампании

  • Левая колонка: Информация о пилоте (настраиваемое фото и личные данные), хронологическая шкала повышений и наград
  • Средняя колонка: Статистика карьеры, включая:
    • Общее количество сбитых воздушных и наземных целей
    • Результаты миссий
    • Распределение использования самолетов
    • и многое другое
  • Правая колонка: отчеты по миссиям с подробными результатами боя и главы сюжета с ИИ (если сгенерированы)
  • Кнопка «Назад»: вернуться к обзору кампании

Язык для каждой кампании: Страница с подробностями может отображаться на языке, отличном от глобальной настройки. Это настраивается в диспетчере настроек на вкладке «Кампании». Если для кампании задано переопределение языка, страница с подробностями (включая отчеты) будет отображаться на этом языке, а страница приветствия останется на вашем глобальном языке.

Настройка информации о пилоте

Нажмите на фотографию пилота или поля с именем, чтобы настроить:

  • Фото пилота: нажмите, чтобы загрузить новую фотографию (поддерживаются распространенные форматы изображений)
  • Личная информация: редактирование фамилии, имени, даты рождения, места рождения и страны рождения
  • Все изменения сохраняются автоматически и сохраняются между сессиями

Устранение неполадок

Проблема: «Загрузка кампаний...» отображается бесконечно

Причина: Данные кампании отсутствуют или файлы JSON пусты
Решение:

  • Убедитесь, что вы запускали Campaign Tracker хотя бы один раз
  • Выполните хотя бы одну миссию в любой кампании
  • Убедитесь, что в установке Campaign Tracker присутствуют следующие файлы:
    • campaign_completion_state.json
    • campaign_events.json
    • campaigns_decoded.json
    • campaign_mission_dates.json

Проблема: не запускается служба записей кампаний

Причина: порт 5000 уже используется другим приложением
Решение:

  • Закройте все другие веб-серверы или приложения, использующие порт 5000
  • Если проблема не устранена, перезагрузите компьютер, чтобы освободить порт

Проблема: В браузере отображается сообщение «Не удается установить соединение» или «Страница не найдена»

Причина: Сервер приложений не запустился
Решение:

  • Убедитесь, что в каталоге установки присутствуют как файл Campaign_Service_Record.exe, так и папка _internal
  • Убедитесь, что ваш антивирус не блокирует приложение
  • Попробуйте запустить Campaign_Service_Record.exe от имени администратора

Проблема: При нажатии на кампанию появляется сообщение «Не удалось загрузить сведения о кампании»

Причина: Отсутствуют или повреждены данные кампании
Решение:

  • Запустите Campaign Tracker еще раз, чтобы перегенерировать файлы JSON
  • Убедитесь, что в кампании есть хотя бы одна выполненная миссия
  • Убедитесь, что имена кампаний в файлах JSON согласованы

Проблема: Не удается загрузить фотографию пилота

Причина: Неподдерживаемый формат файла или файл слишком большой
Решение:

  • Используйте распространенные форматы изображений (JPG, PNG, BMP)
  • Убедитесь, что размер файла изображения не превышает 5 МБ
  • Попробуйте преобразовать изображение в формат PNG

Проблема: Приложение закрывается сразу после запуска

Причина: возможно, тайм-аут бездействия в 60 секунд слишком короткий, или браузер не открылся
Решение:

  • Снова дважды щелкните Campaign_Service_Record.exe
  • Откройте браузер вручную и перейдите на страницу http://127.0.0.1:5000
  • Оставьте вкладку браузера активной, чтобы предотвратить автоматическое закрытие

Проблема: На немецких наградах и изображениях не отображается свастика

Причина:
Campaign Tracker не поддерживает, не одобряет и не пропагандирует национал-социалистическую идеологию или символы в любой форме.
В целях соблюдения законодательных норм в различных странах и в соответствии со стандартами сообщества свастики и другие связанные с ними символы были удалены из изображений, поставляемых по умолчанию с данным программным обеспечением.

Решение:
Пользователи, которым требуются исторически точные изображения, могут заменить изображения локально:

  • Замените изображения наград в
    <путь к IL-2 BoS>\data\swf\CampaignRanksAwards\Germany

  • Замените изображения немецкого фона и флага в
    <папка установки трекера>\_internal\static\images\background_Germany.png
    <папка установки трекера>\_internal\static\images\german_flag.png

⚠️ После замены содержимого изображения необходимо сохранить исходные имена и типы файлов.

Техническая информация

  • Адрес сервера: http://127.0.0.1:5000 (только локальный компьютер)
  • Автоматическое завершение работы: сервер автоматически останавливается после 60 секунд бездействия
  • Расположение данных: Считывает файлы JSON из того же каталога, что и исполняемый файл
  • Совместимость с браузерами: Работает со всеми современными браузерами (Chrome, Firefox, Edge)
  • Сеть: не требует подключения к Интернету; работает полностью на вашем локальном компьютере

🪖 Запись службы карьеры

«Career Service Record» — это отдельное веб-приложение для встроенного режима «Карьера» в игре IL-2 (не для режима «Кампания»). Оно считывает данные о вашей карьере непосредственно из собственной базы данных SQLite cp.db игры — никаких отдельных трекеров или файлов данных не требуется. Оно отображает полную историю службы вашего пилота на всех театрах военных действий, включая повышения в звании, награды, миссии, отчеты, боевую статистику и сюжетные главы, сгенерированные ИИ.

⚠️ ВАЖНО: Для работы Career Service Record необходимо, чтобы в системе была установлена игра IL-2 Sturmovik: Great Battles и в игре была начата хотя бы одна карьера. Приложение считывает файлы данных игры напрямую и не зависит от файлов Campaign Tracker.

Особенности

  • Хронология прохождения театра военных действий: отображает полную цепочку театров военных действий, в которых участвовал ваш пилот (например, Битва за Москву → Битва за Сталинград → Курская битва), в правильном хронологическом порядке
  • Хронология событий карьеры: хронологический список всех событий карьеры, взятых из базы данных игры:
    • Повышения — каждое повышение в звании с датой и изображением звания
    • Награды и знаки отличия — завоеванные медали с изображениями и описаниями
    • Назначения на должность командира — когда ваш пилот был назначен командиром эскадрильи или его заместителем
    • Переводы из эскадрильи — переводы между эскадрильями с указанием исходной и принимающей части
    • Восстановление / Медицинский отпуск — периоды восстановления после травм с датой начала, датой окончания и продолжительностью в днях
  • Отображение должности пилота: если ваш пилот в настоящее время занимает командную должность, она отображается рядом с названием эскадрильи:
    • Командир (нем. Staffelkapitän)
    • Заместитель командира (нем. Stellv. Staffelkapitän)
  • Статистика карьеры: совокупные боевые результаты, взятые непосредственно из таблицы пилотов в игре:
    • Очки PCP (боевые очки пилота)
    • Сбитые самолеты, уничтоженные наземные цели, уничтоженные транспортные средства
    • Выполненные миссии и их результаты
    • Использование самолетов с правильно отображаемыми именами
  • Подведение итогов миссий: анализирует связанные файлы missionReport и отображает подробные отчеты по каждому вылету — включая тип миссии (например, «Патрулирование на передовой», «Сопровождение бомбардировщиков»), размер и роль формирования, уничтожения по категориям и результаты пилотов. Отчеты кэшируются и формируются в фоновом режиме при первой загрузке.
  • Главы истории ИИ: при настройке историй ИИ рядом с каждым отчетом о миссии отображается глава повествовательного военного дневника (см. «Генерация истории ИИ»)
  • Отчет о карьере в формате PDF: создайте PDF-файл для печати, содержащий полную информацию о вашей карьере — включая таблицы сбитых самолетов по каждой миссии, статистику миссий, награды и повышения в звании с полноразмерными изображениями медалей, главы истории ИИ и сводную статистику по всей карьере. Запускается с помощью кнопки «Скачать PDF» на странице с подробностями о карьере
  • Профиль пилота: настраиваемая фотография пилота, дата рождения, место рождения и страна рождения для каждой карьеры — сохраняются между сессиями
  • Выбор стиля немецких наград: Выбор между стилем эпохи Бундесвера 1957 года по умолчанию и оригинальным стилем военного времени для изображений немецких наград (настраивается в Менеджере настроек)
  • Адаптивный дизайн: лаконичный, современный интерфейс, который работает на экранах любого размера
  • Полная локализация: весь текст интерфейса, метки событий и названия званий/наград соответствуют выбранному вами языку. Каждая карьера также может отображаться на другом языке, если это настроено
  • Коррекция согласованности базы данных: при запуске Career Service Record автоматически сверяет счетчики подсчета уничтоженных самолетов (killLightPlane, killMediumPlane, killHeavyPlane) для пилотов эскадрилий ИИ в файле cp.db, исправляя известную ошибку игры, при которой итоговые значения родительских элементов устаревают

Как использовать

  1. Найдите файл Career_Service_Record.exe в каталоге установки Campaign Tracker
  2. Дважды щелкните Career_Service_Record.exe, чтобы запустить приложение (или запустите его из графического интерфейса Control Center)
  3. Ваш браузер по умолчанию откроется автоматически и отобразит обзор вашей карьеры
  4. Щелкните по любой карьере, чтобы просмотреть полную служебную запись с временной шкалой, статистикой и отчетами
  5. Сервер автоматически отключится через 60 секунд бездействия

Примечание: Career Service Record подключается к каталогу игры IL-2. Если он не может найти файл cp.db игры, убедитесь, что IL-2 установлена и что вы начали хотя бы одну карьеру в игре.

Обзор интерфейса

Страница

  • Левая панель: фотография пилота и обзор службы (количество карьер, общее количество миссий, сводка уничтожений)

Устранение неполадок

Проблема: «Загрузка вакансий...» отображается бесконечно

Причина: База данных вакансий не найдена или вакансий нет Решение:

  • Убедитесь, что игра IL-2 Sturmovik: Great Battles установлена
  • Начните хотя бы одну карьеру в игре перед запуском этого приложения
  • Убедитесь, что каталог игры указан правильно (Career Service Record автоматически определяет путь установки IL-2 из реестра Windows)

Проблема: Career Service Record не запускается

Причина: порт 5001 уже используется другим приложением Решение:

  • Закройте все другие веб-серверы или приложения, использующие порт 5001
  • Если проблема не устраняется, перезагрузите компьютер, чтобы освободить порт

Проблема: В браузере отображается сообщение «Не удается установить соединение» или «Страница не найдена»

Причина: Сервер приложений не запустился Решение:

  • Убедитесь, что в каталоге установки присутствуют как Career_Service_Record.exe, так и папка _internal
  • Убедитесь, что ваш антивирус не блокирует приложение
  • Попробуйте запустить Career_Service_Record.exe от имени администратора
  • Откройте браузер вручную и перейдите по адресу http://127.0.0.1:5001

Проблема: Отсутствуют события или отчеты

Причина: Файлы отчетов о миссиях еще не проанализированы (первая загрузка) Решение:

  • Подождите немного после открытия страницы с подробностями о вакансии — отчеты анализируются в фоновом режиме при первой загрузке
  • Перезагрузите страницу через несколько секунд; во время анализа появится индикатор выполнения

Проблема: Главы сюжета ИИ не отображаются

Причина: Истории ИИ не включены или не настроены Решение:

  • Откройте IL2_Settings_Manager.exe → вкладка «AI Stories»
  • Убедитесь, что для параметра «AI Stories» установлено значение «Yes» и введены действительный ключ API и модель
  • Нажмите «Generate» в интерфейсе Service Record или включите функцию «Auto-Generate» в Settings Manager

Техническая информация

  • Адрес сервера: http://127.0.0.1:5001 (только локальный компьютер)
  • Автоматическое завершение работы: сервер автоматически останавливается после 60 секунд бездействия
  • Источник данных: считывает данные напрямую из <установка IL-2>\data\Career\cp.db
  • Совместимость с браузерами: Работает со всеми современными браузерами (Chrome, Firefox, Edge)
  • Сеть: не требует подключения к Интернету; работает полностью на вашем локальном компьютере (для генерации сюжетов с помощью ИИ требуется подключение к Интернету для доступа к настроенному поставщику LLM)

❓ Часто задаваемые вопросы

Почему моя пользовательская кампания не обнаруживается / миссии не обнаруживаются?

О: Трекер анализирует файлы миссий для извлечения дат и метаданных. Чтобы ваша пользовательская кампания была правильно обнаружена, следуйте этим золотым правилам:

⚠️ Важно: для чтения требуются файлы локализации на английском языке

Трекер считывает только файлы локализации на английском языке (.eng briefings и info.locale=eng.txt) для извлечения дат миссий и информации о кампании. IL-2 сохраняет языковые настройки пользователя внутренне, и у нас нет возможности определить, какой язык вы используете в игре. Поэтому:

  • Каждая миссия должна иметь соответствующий файл с инструкциями в формате .eng (например, 01.eng для 01.Mission)
  • В папке кампании должен находиться файл info.locale=eng.txt с описанием кампании

Даже если вы играете на другом языке, эти английские файлы должны присутствовать, чтобы трекер работал. Трекер не будет считывать файлы .ger, .rus, .fra или файлы на других языках для извлечения дат.

ℹ️ Многоязычный вывод

При записи событий и отчетов обратно в вашу кампанию трекер автоматически обновляет все существующие файлы info.locale=*.txt. Каждый файл записывается на соответствующем языке:

  • info.locale=eng.txt → Содержание на английском языке
  • info.locale=ger.txt → Содержание на немецком языке (Deutsch)
  • info.locale=fra.txt → Содержание на французском языке (Français)
  • info.locale=spa.txt → Содержание на испанском языке (Español)
  • info.locale=pol.txt → польский контент (Polski)
  • info.locale=rus.txt → Содержание на русском языке (Русский)
  • info.locale=chs.txt → Содержание на китайском языке (简体中文)

См. раздел «Поддерживаемые языки» для получения более подробной информации.

Именование файлов миссий:

  • Используйте числовые префиксы для порядка миссий: 01.Mission, 02.Mission, 03.Mission или 1.Mission, 2.Mission и т. д.
  • Также работает именование на основе даты: 1943-07-04.Mission, 1943-07-04a.Mission
  • Поддерживаемые расширения: .Mission, .mission, .msnbin

Определение даты миссии (в файлах брифингов .eng ): Трекер ищет информацию о дате в следующем порядке приоритета:

  1. Date: поле в брифинге (например, Date: 4 ноября 1943 г.)
  2. Поле«Time:» для времени начала миссии (например, Time: 09:45)
  3. Имя файла, если оно содержит дату (например, 1943-07-04.Mission)

Поддерживаемые форматы даты:

  • 4 ноября 1943 г. или 4 ноября 1943
  • 4 ноября 1943 г. (без запятой)
  • 04.11.1943 или 11.04.1943 (ДД.ММ.ГГГГ или ММ.ДД.ГГГГ)
  • 1943-07-04 (формат ISO в имени файла)

  3. Вы можете вручную установить/исправить это в графическом интерфейсе Country Validator при первом запуске или настроить позже вручную в файле stock_campaigns.yaml

Распространенные проблемы:

  • Отсутствует файл брифинга .eng → даты не могут быть извлечены (миссия по-прежнему будет отслеживаться как «Миссия 1», «Миссия 2» и т. д., но без информации о дате)
  • Отсутствует файл info.locale=eng.txt → описание кампании недоступно, трекер не может прочитать информацию о кампании
  • Нестандартный формат даты в брифинге → используйте один из поддерживаемых форматов, указанных выше
  • Специальные символы в названии папки кампании → избегайте умляутов или специальных символов
  • Кампании Первой мировой войны (Flying Circus) → исключены по умолчанию (см. раздел «Обнаружение и исключение Первой мировой войны»)

В: Могу ли я запускать несколько экземпляров трекера?

О: Нет. Одновременно мониторить ваши кампании должен только один экземпляр.

В: Вносит ли трекер изменения в мою установку IL-2?

О: Трекер изменяет только:

  • Файлы info.locale=eng.txt кампаний (добавляет раздел «События»)
  • Создает файлы резервных копий в папке usersave

Он не изменяет никаких исполняемых файлов игры или основных файлов.

В: Будет ли это работать с модами?

О: Да, при условии, что мод использует стандартную структуру кампании. Пользовательские кампании автоматически обнаруживаются при первоначальной настройке.

В: Могу ли я вручную редактировать конфигурацию?

О: Да, но для большинства изменений мы рекомендуем использовать Менеджер настроек (IL2_Settings_Manager.exe). Он предоставляет удобный интерфейс и автоматически выполняет перегенерацию при необходимости.

Для расширенной настройки файл campaign_progress_config.yaml можно отредактировать вручную, чтобы:

  • Настройка пороговых значений баллов для продвижения
  • Изменение критериев награждения
  • Добавление пользовательских наград
  • Изменение коэффициентов масштабирования рангов

⚠️ Всегда создавайте резервную копию перед ручным редактированием файлов конфигурации.

В: Как сбросить все настройки?

О: Удалите эти файлы и перезапустите трекер:

  • campaign_mission_dates.json
  • campaign_popups_seen.json
  • campaigns_decoded.json
  • campaign_events.json

В: Поддерживается ли многопользовательский режим?

О: Трекер предназначен для одиночных карьерных кампаний. Многопользовательские миссии не генерируют ту же структуру данных сохранения.

В: Почему мне нужно перезапускать IL-2, чтобы увидеть новые события?

О: IL-2 загружает описание кампании (info.locale=eng.txt) при запуске игры и кэширует его в памяти. Изменения, внесенные трекером, записываются в файл, но не появятся в игре, пока вы не перезапустите IL-2. Однако вы по-прежнему будете видеть всплывающие окна сразу же, когда получите повышения или награды.

В: Что произойдет, если я удалю файл резервной копии вручную?

О: Индекс резервных копий (campaignsstates_hash_index.json) по-прежнему будет на него ссылаться, но интерфейс восстановления пропустит все резервные копии, где отсутствует фактический файл резервной копии.

В: Могу ли я использовать трекер с Flying Circus (Первая мировая война)?

О: Кампании Flying Circus по умолчанию обнаруживаются и исключаются. Трекер разработан для кампаний Второй мировой войны и не включает звания и награды эпохи Первой мировой войны. Вы можете управлять исключениями на этапе проверки страны (флажок «игнорировать» для Первой мировой войны), но кампании Первой мировой войны не будут иметь исторически точных званий и наград.

В: Могу ли я использовать трекер с Campaign Generator (PWCG) Пэта Уилсона?

О: Нет — этот трекер НЕ работает с PWCG, но и НЕ мешает ему.

В: Нужно ли подключение к Интернету для использования трекера?

О: Нет — трекер и обе службы «Service Records» работают полностью в автономном режиме. Подключение к Интернету требуется только при генерации глав истории ИИ (для доступа к вашему настроенному провайдеру LLM). Все остальные функции — мониторинг, подведение итогов, повышения, награды, отчеты в формате PDF и интерфейс «Service Record» — работают без подключения к Интернету.

В: Какую модель LLM следует использовать для AI-историй?

О: Для OpenAI модель gpt-4o-mini предлагает оптимальный баланс качества и стоимости. Для OpenRouter openai/gpt-4o-mini является надежным выбором по умолчанию. Для Anthropic модель claude-3-5-haiku-20241022 отличается высокой скоростью и эффективностью. Любая модель, которая надежно возвращает JSON и генерирует связный текст объемом 150–400 слов на ответ, подойдет.

В: Сколько стоит генерация историй с помощью ИИ?

О: Стоимость полностью зависит от вашего провайдера и модели. Типичная глава карьерной истории (180–380 слов) использует около 1500–3000 токенов на задание. По ценам gpt-4o-mini (по состоянию на 2025 год) это составляет менее 0,01 доллара за главу. Полная карьера из 100 заданий обойдется примерно в 0,50–1,00 доллара с этой моделью.
