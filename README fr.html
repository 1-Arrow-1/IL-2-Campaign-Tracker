Suivi de progression de la campagne IL-2

Un outil de suivi complet pour les campagnes solo de la Seconde Guerre mondiale dans IL-2 Sturmovik Great Battles. Il surveille automatiquement la progression de votre campagne, calcule les promotions et les récompenses selon des critères historiques, génère des comptes rendus détaillés des missions et crée des rapports PDF sur la carrière de votre pilote.

Changement de langue

Vous pouvez changer de langue à l'aide du Gestionnaire de paramètres (voir la section Gestionnaire de paramètres ) :

  1. Ouvrez IL2_Settings_Manager.exe
  2. Sélectionnez votre langue préférée dans le menu déroulant (les langues sont affichées sous leur nom d'origine)
  3. Cliquez sur « Appliquer » ou « OK »
  4. Le tracker régénérera automatiquement tous les débriefings et rapports PDF dans la nouvelle langue

Remarque : lorsque vous changez de langue, tous les débriefings de campagne et rapports PDF existants sont automatiquement régénérés dans la langue sélectionnée. Cela peut prendre un certain temps selon le nombre de campagnes que vous avez.

📥 Installation

Étape 1 : Téléchargement et installation

  1. Téléchargez la dernière version (IL2_CampaignTracker_Setup_v2.2_ML.exe.zip)

  2. Décompressez le fichier zip

  3. Exécutez le fichier IL2_CampaignTracker_Setup_v2.2_ML.exe

  4. Suivez les instructions d'installation de l'assistant de configuration

L'assistant d'installation vous guidera dans la sélection du répertoire d'installation et la configuration des options de base.

Étape 2 : Extraire les campagnes standard (facultatif mais recommandé)

⚠️ IMPORTANT : le tracker ne peut surveiller que les campagnes situées dans <Chemin d'accès à IL-2 BoS>\data\campaigns. Les campagnes IL-2 standard ne sont pas stockées directement dans ce dossier ; elles sont plutôt exécutées en interne à partir de campaigns.gtp. Par conséquent, ces campagnes doivent être extraites avant de pouvoir être suivies.

🚨 ATTENTION : Si vous avez modifié des missions appartenant à une campagne officielle standard, procédez avec une extrême prudence lorsque vous copiez les fichiers extraits de campaigns.gtp dans le dossier <Chemin d'accès à IL-2 BoS>\data\campaigns. Les fichiers existants seront écrasés, et toutes les modifications apportées aux missions personnalisées seront remplacées par les versions d'origine prêtes à l'emploi.

Pour extraire les campagnes standard :

  1. Téléchargez unGTP-IL2 à partir de : https://www.mediafire.com/file/caxpalaudz1hd47/unGTP-IL2.zip
  2. Décompressez et déplacez le fichier unGTP-IL2.exe vers <Chemin d'accès à IL-2 BoS>\data
  3. Faites glisser le fichier Campaigns.gtp sur unGTP-IL2.exe (ignorez le message d'erreur qui s'affiche à la fin dans la fenêtre cmd : tout a été extrait)
  4. Accédez à <Chemin d'accès à IL-2 BoS>\data\(null)\campaigns
  5. Copiez tous les sous-dossiers vers <Chemin d'accès à IL-2 BoS>\data\campaigns

Remarque : l'extraction des campagnes officielles standard a pour SEUL but de les rendre utilisables par le Campaign Tracker. Veuillez ne pas modifier les campagnes officielles.

Étape 3 : Exécutez le Tracker

Lancez IL2_Campaign_Tracker.exe depuis le répertoire d'installation du Tracker.

ℹ️ REMARQUE: par défaut, le Tracker se ferme automatiquement lorsque IL-2 BoS est fermé. Pour continuer à utiliser le Tracker, vous devez soit le redémarrer manuellement, soit configurer une tâche dans le Planificateur de tâches de Windows pour qu'il se lance automatiquement au démarrage de Windows.

Vous trouverez un guide de configuration général ici : https://forum.il2-series.com/topic/772-expanded-career-rank-mod/#findComment-4176

🚀 Configuration lors du premier lancement

Lorsque vous lancez le tracker pour la première fois, un assistant de configuration vous guide tout au long du processus :

Étape 1 : Sélectionnez le répertoire du jeu

Un navigateur de dossiers s'ouvre. Accédez à votre dossier d'installation d'IL-2 :

Exemple : C:\Program Files (x86)\Steam\steamapps\common\IL-2 Sturmovik Battle of Stalingrad

Important : sélectionnez le dossier principal du jeu, et NON le sous-dossier data\Campaigns.

Étape 2 : Validation du pays

Le tracker analyse toutes les campagnes installées et tente de détecter le pays correspondant à chacune d'entre elles. Une interface graphique de validation s'affiche, dans laquelle vous pouvez :

  • ✅ Confirmez les pays détectés automatiquement
  • ✏️ Corrigez les campagnes mal identifiées
  • 🚫 Exclure les campagnes de la Première Guerre mondiale (Flying Circus)

Ceci est important car les promotions et les récompenses sont spécifiques à chaque pays.
ℹ️ Une fois les pays validés/corrigés, ces campagnes sont enregistrées dans le fichier stock_campaigns.yaml. Si vous avez accidentellement attribué un mauvais pays, vous pouvez corriger cela en modifiant manuellement le pays dans le fichier stock_campaigns.yaml.

Détection WW1 (Flying Circus)

Si le tracker détecte des campagnes Flying Circus, vous pouvez – ou plutôt devriez – les marquer comme WW1 (ignorer) dans cet écran afin qu'elles soient exclues du suivi.

Étape 3 : Prêt pour le suivi

Une fois la configuration terminée, le tracker :

  1. Décode votre fichier de sauvegarde de campagne actuel
  2. Génère les événements initiaux (promotions/récompenses existantes)
  3. Lance la surveillance des modifications

Cette fonctionnalité est utile lorsque vous souhaitez consulter les comptes rendus d'une campagne allemande en allemand tout en conservant le reste de l'application dans votre langue préférée. Lorsque vous modifiez ce paramètre et que vous enregistrez, les comptes rendus localisés sont automatiquement régénérés pour les campagnes concernées.

🪖 Détection et exclusion de la Première Guerre mondiale

Les campagnes Flying Circus (Première Guerre mondiale) sont détectées et exclues par défaut, car le tracker ne prend en compte que les grades, les distinctions et la logique de débriefing de la Seconde Guerre mondiale.

Les signaux de détection comprennent :

  • Dates des missions comprises entre 1914 et 1918
  • Mots-clés relatifs aux avions de la Première Guerre mondiale dans les données de campagne
  • Mots-clés « Flying Circus »/Première Guerre mondiale dans les descriptions de campagne

Fonctionnement de l'exclusion :

  • Les campagnes exclues sont ignorées lors du décodage et de la génération d'événements.
  • La raison de l'exclusion est enregistrée dans campaign_mission_dates.json afin que le tracker les ignore systématiquement.
  • Vous pouvez consulter ou modifier les exclusions en relançant la configuration (supprimez le fichier campaign_mission_dates.json et l'entrée correspondante dans le fichier stock_campaigns.yaml) et en cochant la case WW1 (ignorer) dans l'interface graphique de validation du pays.

🎖️ Système de promotions et de récompenses

Fonctionnement des promotions

Les promotions sont basées sur le score cumulé de toutes les missions terminées (la valeur du score provient du fichier campaignsstates.txt et est calculée selon les règles internes d'IL-2 GB) :

Score global par campagne = ∑ Scores des missions
Score de promotion = Score de base × Facteur d'échelle de rang

Le facteur d'échelle de rang ajuste les exigences en fonction de la durée de la campagne (peut être modifié dans campaign_progress_config.yaml) :

« 1-10 » : 1,00 # Campagnes courtes (campagnes standard)
« 11-20 » : 1,15 # Campagnes moyennes à courtes
« 21-30 » : 1,30 # Campagnes moyennes
« 31-40 » : 1,50 # Campagnes moyennes à longues
« 41-50 » : 1,75 # Campagnes longues
« 51-70 » : 2,00 # Campagnes très longues
« 71+ » : 5,50 # Campagnes épiques (70 missions et plus)

Cela empêche les promotions rapides dans les campagnes longues tout en garantissant une progression équitable dans les campagnes courtes.

ℹ️ Exemple : dans une campagne de 24 missions, le facteur d'échelle est de 1,3. Ainsi, un grade nécessitant 1 000 points demanderait en réalité 1 300 points (1 000 x 1,30) pour être atteint.
Lorsque votre score cumulé atteint ou dépasse le seuil de promotion de 1 300 points, vous êtes promu au grade suivant.

🚨 IMPORTANT: si vous modifiez le fichier campaign_progress_config.yaml, veillez à conserver une indentation correcte (format YAML). Une indentation incorrecte peut entraîner des erreurs d'analyse.

Fonctionnement des récompenses

Les récompenses sont attribuées en fonction de divers critères définis dans le fichier campaign_progress_config.yaml et s'inspirent du mode carrière d'IL-2 BoS. Toutes les conditions d'obtention des récompenses sont des conditions « OU »:

Type de critère Exemple
Nombre cumulé de victoires 8 points de combat aérien → Croix de fer de 1re classe
Mission unique 7 victoires en une seule sortie → Médaille d'honneur
Missions accomplies 15 missions → Ordre de l'Étoile rouge
Blessé au combat Dégâts subis par le pilote > 20 % → Insigne de blessé
Aléatoire + Seuil Nombre élevé de victimes + facteur chance → Décorations rares

Certaines récompenses ont des prérequis (par exemple, il faut avoir la Croix de fer de 2e classe avant celle de 1re classe) et s'excluent mutuellement (par exemple, il n'est pas possible d'obtenir les deux variantes de bande de blessure lors d'une même mission).

Décalage du grade de départ

Les campagnes peuvent commencer avec des grades plus élevés (si vous le souhaitez). Cela est utile pour les campagnes où votre pilote est déjà un officier expérimenté au début de la mission. Le décalage peut être configuré :

Option 1 : via le Gestionnaire de paramètres (recommandé)

  1. Ouvrez IL2_Settings_Manager.exe
  2. Accédez à l'onglet « Campagnes »
  3. Double-cliquez sur une campagne pour modifier son décalage
  4. Sélectionnez une valeur comprise entre 0 et 7

Option 2 : Modification manuelle dans campaign_mission_dates.json:

"kerch": {
  "country": "Germany",
  "starting_rank_offset": 2, --> modifiez ce chiffre (0-7, par défaut = 0)
  "missions": {...  }
}

Remarque : les valeurs de décalage élevées (jusqu'à 7) sont particulièrement utiles pour les campagnes britanniques, qui comportent de nombreux grades inférieurs, ou pour les campagnes où le joueur commence en tant que chef d'escadron.

ℹ️ Remarque : vous pouvez personnaliser les critères de promotion et de récompense selon vos préférences. Cependant, il est fortement recommandé de créer une copie de sauvegarde du fichier campaign_progress_config.yaml d'origine avant d'effectuer toute modification.

📊 Débriefings de mission

Source des données

Les données de débriefing sont extraites des fichiers journaux de mission d'IL-2 (fichiers.mlg ) :

Emplacement : [Répertoire IL-2]\data\FlightLogs\[mission].mlg

Ces fichiers binaires contiennent des enregistrements détaillés de tout ce qui s'est passé pendant la mission. Ces fichiers binaires sont « traduits » par mlg2txt.exe en un fichier *.txt, puis traités ultérieurement.

Résultats du débriefing

Chaque mission génère un rapport détaillé dans deux formats :

  1. En jeu (Journal de vol) - Liste chronologique des événements enregistrés dans tous les fichiers info.locale=*.txt de la campagne (chacun dans sa langue respective)
  2. Rapport PDF - Répartition détaillée des victoires par catégorie, correspondant à l'écran des résultats en jeu (dans la langue que vous avez sélectionnée)

Remarque : le tracker enregistre le contenu localisé dans chaque fichier de langue présent dans votre dossier de campagne. Par exemple, si votre campagne contient à la fois info.locale=eng.txt et info.locale=ger.txt, le fichier anglais contiendra les débriefings en anglais et le fichier allemand contiendra les débriefings en allemand.

🧹 Nettoyage de la mission

Qu'est-ce que takeoffStatus ?

IL-2 suit l'achèvement de la mission à l'aide d'un indicateur takeoffStatus:

Valeur Signification
takeoffStatus=1 Mission commencée mais non terminée correctement
takeoffStatus=2 Mission terminée avec succès

Quand l'interface graphique de nettoyage s'affiche

L'interface graphique de nettoyage de mission s'affiche au démarrage du tracker lorsque des missions avec takeoffStatus=1 sont détectées.

Causes courantes de takeoffStatus=1:

  • ❌ Objectif de mission non atteint
  • 🪂 Pilote s'est éjecté
  • 💀 Pilote tué au combat (KIA)
  • ❓ Pilote porté disparu au combat (MIA)
  • 💥 L'IL-2 s'est écrasé pendant la mission
  • 🚫 Fermeture forcée (Alt+F4, Gestionnaire des tâches)
  • 🔌 Coupure de courant / plantage du système

Remarque : toutes les missions où takeoffStatus=1 ne sont pas « échouées » au sens traditionnel du terme. S'éjecter ou être tué au combat peut faire partie d'une stratégie de jeu intentionnelle. L'outil de nettoyage vous permet de choisir de supprimer ou non ces missions.

Interface graphique de nettoyage

┌─────────────────────────────────────────────────────────┐
│        ⚠️ Missions incomplètes détectées                  │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Les missions suivantes n'ont pas été correctement menées à bien :     │
│                                                          │
│  ☐ kerch - Mission 05 (14 novembre 1943)               │
│  ☐ blazingsteppe - Mission 12 (9 septembre 1942)       │
│                                                          │
│  Sélectionnez les missions à supprimer de votre sauvegarde de campagne.      │
│                                                          │
│  [🗑️ Supprimer la sélection]  [▶ Tout conserver]                     │
│                                                          │
└─────────────────────────────────────────────────────────┘

Que se passe-t-il lorsque vous supprimez une mission

  1. Sauvegarde créée - État actuel enregistré avant toute modification
  2. Mission supprimée - Entrée supprimée du fichier campaignsstates.txt
  3. État des fenêtres contextuelles effacé - Événements associés supprimés de campaign_popups_seen.json
  4. Prêt à rejouer - Vous pouvez rejouer la mission

Que se passe-t-il lorsque vous conservez une mission

Si vous cliquez sur « Tout conserver » ou si vous ne sélectionnez aucune mission :

  • Aucune sauvegarde n'est créée
  • Aucune modification n'est effectuée
  • La mission reste dans votre fichier de sauvegarde
  • L'interface de nettoyage s'affichera à nouveau la prochaine fois (pour les missions incomplètes restantes)

💾 Système de sauvegarde et de restauration

Quand les sauvegardes sont-elles créées ?

Les sauvegardes ne sont créées que lorsque vous supprimez des missions incomplètes via l'outil de nettoyage des missions. Elles ne sont pas créées automatiquement après chaque mission.

Cela vous permet de restaurer votre campagne à l'état où elle se trouvait avant que vous ne supprimiez des missions.

Interface graphique de restauration

Lorsque le tracker démarre et que des sauvegardes sont disponibles, une interface graphique de restauration peut s'afficher :

┌─────────────────────────────────────────────────────────┐
│           🔄 Restaurer la sauvegarde de la campagne                    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Sélectionnez une sauvegarde à restaurer :                            │
│                                                         │
│  ┌────────────────────────────────────────────────────┐ │
│  │ Date et heure          │ Statut           │ Fenêtres contextuelles   │ │
│  ├──────────────────────┼──────────────────┼──────────┤ │
│  │ 15/01/2024 14:30:22  │ Actuellement active │ ✓ Oui    │ │
│  │ 15/01/2024 12:15:03  │                  │ ✓ Oui    │ │
│  │ 14/01/2024 20:45:11  │                  │ ✗ Non     | │
│  └────────────────────────────────────────────────────┘ │
│                                                         │
│  [🔄 Restaurer la sélection]  [▶ Continuer]  [✕ Quitter]         │
│                                                         │
└─────────────────────────────────────────────────────────┘

Lorsque l'interface graphique s'affiche :

  • Il existe plusieurs sauvegardes, OU
  • Il existe une sauvegarde qui ne correspond pas à l'état actuel

Lorsque l'interface graphique n'apparaît PAS :

  • Il n'existe aucune sauvegarde
  • Il n'existe qu'une seule sauvegarde et elle correspond déjà à l'état actuel

Processus de restauration

  1. Sélectionnez une sauvegarde dans la liste
  2. Cliquez sur « Restaurer la sauvegarde sélectionnée »
  3. Confirmez l'action
  4. Tracker effectue automatiquement :
    • Crée une copie du fichier de sauvegarde (la sauvegarde d'origine est conservée)
    • Supprime le fichier campaignsstates.txt actuel
    • Renomme la copie de sauvegarde en campaignsstates.txt
    • Régénère tous les événements
    • Restaure l'état correspondant de la fenêtre contextuelle (évite les doublons)

Exemple de cas d'utilisation

1. Vous jouez la mission 05 de la campagne « kerch »
2. IL-2 plante en cours de mission → takeoffStatus=1
3. Au prochain démarrage du tracker : l'interface de nettoyage s'affiche
4. Vous sélectionnez la mission 05 et cliquez sur « Supprimer »
5. Le tracker crée une sauvegarde AVANT de supprimer la mission
6. La mission 05 est supprimée du fichier de sauvegarde
7. Vous pouvez désormais rejouer la mission 05

Plus tard, si nécessaire : 
8. Lancez le tracker → l'interface graphique de restauration s'affiche
9. Sélectionnez la sauvegarde effectuée avant la suppression
10. La campagne est restaurée dans son état AVEC la mission 05 (incomplète)

📋 Dossier de service de campagne

Le dossier de service de campagne est une application web qui offre une vue élégante et en lecture seule de la carrière de votre pilote à travers toutes les campagnes en cours et terminées. Il présente votre historique de service dans un format clair et professionnel, idéal pour passer en revue vos exploits ou partager votre dossier de combat.

⚠️ IMPORTANT: le dossier de service de campagne n'est pas un système autonome. Il fonctionne exclusivement en conjonction avec le tracker et ses fichiers associés, qui fournissent les données de campagne requises.

Fonctionnalités

  • Aperçu des campagnes: Parcourez toutes les campagnes auxquelles vous avez participé, avec les missions accomplies, les promotions obtenues et les récompenses reçues
  • Dossier de service détaillé: cliquez sur n'importe quelle campagne pour afficher :
    • L'historique complet des missions avec les débriefings
    • Chronologie des promotions et des récompenses
    • Les statistiques de carrière (victimes aériennes, victimes au sol, taux de réussite des missions)
    • Utilisation des appareils et analyse des performances
  • Profil du pilote: affichage et personnalisation du nom, de la photo et des informations personnelles du pilote pour chaque campagne
  • Conception réactive: interface épurée et moderne qui s'adapte à toutes les tailles d'écran
  • Génération automatique: lit automatiquement les données de vos fichiers Campaign Tracker - aucune saisie manuelle requise

Mode d'emploi

  1. Recherchez le fichier Campaign_Service_Record.exe dans le répertoire d'installation de Campaign Tracker (voir la section Installation ci-dessus)
  2. Double-cliquez sur Campaign_Service_Record.exe pour lancer l'application
  3. Votre navigateur Web par défaut s'ouvrira automatiquement et affichera votre historique de service
  4. Parcourez vos campagnes et cliquez sur n'importe laquelle pour afficher des statistiques détaillées
  5. Le serveur s'éteindra automatiquement après 60 secondes d'inactivité

Remarque: le dossier de service de campagne nécessite des données provenant du suivi de campagne. Vous devez exécuter le suivi de campagne au moins une fois et accomplir au moins une mission avant que les campagnes n'apparaissent dans le dossier de service.

Présentation de l'interface

Page d'accueil

  • Panneau de gauche: informations sur le pilote (photo, nom, aperçu du service)
  • Panneau de droite: liste de toutes les campagnes avec les missions accomplies
    • Affiche le nombre de missions, les promotions obtenues et les récompenses reçues par campagne
    • Cliquez sur n'importe quelle campagne pour consulter le dossier de service détaillé

Page de détails de la campagne

  • Colonne de gauche: informations sur le pilote (photo personnalisable et données personnelles), chronologie des promotions et des récompenses
  • Colonne centrale: statistiques de carrière, notamment :
    • Nombre total d'ennemis abattus en vol et au sol
    • Résultats des missions
    • Répartition de l'utilisation des appareils
    • et plus encore
  • Colonne de droite: comptes rendus de mission avec résultats de combat détaillés
  • Bouton Retour: Retour à l'aperçu de la campagne

Langue par campagne: la page de détails peut s'afficher dans une langue différente de celle définie dans les paramètres généraux. Ce paramètre se configure dans le Gestionnaire de paramètres, sous l'onglet Campagnes. Lorsqu'une campagne dispose d'une langue spécifique, la page de détails (y compris les débriefings) s'affiche dans cette langue, tandis que la page d'accueil reste dans votre langue par défaut.

Personnalisation des informations sur le pilote

Cliquez sur la photo du pilote ou sur les champs de nom pour personnaliser :

  • Photo du pilote: cliquez pour télécharger une nouvelle photo (formats d'image courants pris en charge)
  • Informations personnelles: Modifier le nom, le prénom, la date de naissance, le lieu de naissance et le pays de naissance
  • Toutes les modifications sont enregistrées automatiquement et conservées d'une session à l'autre

Dépannage

Problème : « Chargement des campagnes... » s'affiche indéfiniment

Cause: aucune donnée de campagne disponible ou fichiers JSON vides
Solution:

  • Assurez-vous d'avoir lancé le Suivi de campagne au moins une fois
  • Accomplissez au moins une mission dans n'importe quelle campagne
  • Vérifiez que votre installation de Campaign Tracker contient les fichiers suivants :
    • campaign_completion_state.json
    • campaign_events.json
    • campaigns_decoded.json
    • campaign_mission_dates.json

Problème : le service d'enregistrement des campagnes ne démarre pas

Cause: le port 5000 est déjà utilisé par une autre application
Solution:

  • Fermez tous les autres serveurs Web ou applications utilisant le port 5000
  • Si le problème persiste, redémarrez votre ordinateur pour libérer le port

Problème : le navigateur affiche « Impossible de se connecter » ou « Page introuvable »

Cause: Le serveur d'applications n'a pas pu démarrer
Solution:

  • Vérifiez que le fichier Campaign_Service_Record.exe et le dossier _internal sont bien présents dans le répertoire d'installation
  • Assurez-vous que votre antivirus ne bloque pas l'application
  • Essayez d'exécuter Campaign_Service_Record.exe en tant qu'administrateur

Problème : lorsque vous cliquez sur une campagne, le message « Échec du chargement des détails de la campagne » s'affiche

Cause: Données de campagne manquantes ou corrompues
Solution:

  • Relancez Campaign Tracker pour régénérer les fichiers JSON
  • Assurez-vous que la campagne comporte au moins une mission terminée
  • Vérifiez que les noms de campagne dans les fichiers JSON sont cohérents

Problème : la photo du pilote ne se télécharge pas

Cause: Format de fichier non pris en charge ou fichier trop volumineux
Solution:

  • Utilisez des formats d'image courants (JPG, PNG, BMP)
  • Assurez-vous que la taille du fichier image est inférieure à 5 Mo
  • Essayez de convertir l'image au format PNG

Problème : L'application se ferme immédiatement après son lancement

Cause: le délai d'inactivité de 60 secondes est peut-être trop court, ou le navigateur ne s'est pas ouvert
Solution:

  • Double-cliquez à nouveau sur Campaign_Service_Record.exe
  • Ouvrez manuellement votre navigateur et accédez à http://127.0.0.1:5000
  • Laissez l'onglet du navigateur ouvert pour éviter qu'il ne se ferme automatiquement

Problème : les distinctions et les images allemandes n'affichent pas la croix gammée

Cause :
Campaign Tracker ne soutient, n'approuve ni ne promeut en aucune manière l'idéologie ou les symboles nationaux-socialistes.
Afin de se conformer aux réglementations légales de plusieurs pays et de respecter les normes communautaires, les croix gammées et autres symboles associés ont été supprimés des images par défaut fournies avec ce logiciel.

Solution :
Les utilisateurs qui ont besoin d'images historiquement fidèles peuvent remplacer les images localement :

  • Remplacez les images de récompenses dans
    <chemin d'accès à IL-2 BoS>\data\swf\CampaignRanksAwards\Germany

  • Remplacez les images d'arrière-plan et de drapeau allemands dans
    <dossier d'installation du tracker>\_internal\static\images\background_Germany.png
    <dossier d'installation du tracker>\_internal\static\images\german_flag.png

⚠️ Les noms de fichiers et types de fichiers d'origine doivent être conservés après le remplacement du contenu de l'image.

Informations techniques

  • Adresse du serveur: http://127.0.0.1:5000 (machine locale uniquement)
  • Arrêt automatique: le serveur s'arrête automatiquement après 60 secondes d'inactivité
  • Emplacement des données: lit les fichiers JSON dans le même répertoire que l'exécutable
  • Compatibilité avec les navigateurs: fonctionne avec tous les navigateurs modernes (Chrome, Firefox, Edge)
  • Réseau: ne nécessite pas de connexion Internet ; fonctionne entièrement sur votre machine locale

🪖 Career Service Record

Le dossier de service de carrière est une application web distincte destinée au mode Carrière intégré à IL-2 (et non au mode Campagne). Il lit vos données de carrière directement à partir de la base de données SQLite cp.db du jeu — aucun tracker ni fichier de données séparé n'est nécessaire. Il présente l'historique complet du service de votre pilote sur tous les théâtres d'opérations, y compris les promotions, les distinctions, les missions, et plus encore.

⚠️ IMPORTANT: le dossier de service de carrière nécessite l'installation d'IL-2 Sturmovik: Great Battles et le lancement d'au moins une carrière dans le jeu. Il lit directement les fichiers de données du jeu et ne dépend pas des fichiers du suivi de campagne.

Fonctionnalités

  • Chronologie des théâtres d'opérations: affiche la liste complète des théâtres d'opérations dans lesquels votre pilote a servi (par exemple, bataille de Moscou → bataille de Stalingrad → bataille de Koursk), dans l'ordre chronologique correct
  • Chronologie des événements de carrière: liste chronologique de tous les événements de carrière extraits de la base de données du jeu :
    • Promotions — chaque avancement de grade avec la date et l'image du grade
    • Récompenses et décorations — médailles obtenues avec images et descriptions
    • Nominations au poste de commandant — lorsque votre pilote a été nommé commandant d'escadron ou commandant en second
    • Transferts d'escadron — transferts entre escadrons indiquant l'unité d'origine et l'unité de destination
    • Convalescence / Congé médical — périodes de convalescence suite à une blessure, avec date de début, date de fin et durée en jours
  • Affichage du rôle du pilote: si votre pilote occupe actuellement un poste de commandement, son rôle est indiqué à côté du nom de l'escadron :
    • Commandant (en allemand : Staffelkapitän)
    • Commandant adjoint (en allemand : Stellv. Staffelkapitän)
  • Statistiques de carrière: résultats de combat cumulés tirés directement du tableau des pilotes du jeu :
    • Score PCP (Points de combat du pilote)
    • Voitures abattues, véhicules détruits
    • Missions effectuées et résultats des missions
  • Debriefings de mission: analyse les fichiers missionReport associés et affiche des débriefings détaillés par sortie. Les débriefings sont mis en cache et générés en arrière-plan lors du premier chargement.
  • Profil du pilote: photo du pilote, date de naissance, lieu de naissance et pays de naissance personnalisables pour chaque carrière — conservés d'une session à l'autre
  • Sélection du style des décorations allemandes: choisissez entre le style par défaut de l'époque de la Bundeswehr (1957) et le style original de la période de guerre pour les images des décorations allemandes (configuré lors de l'installation)
  • Conception réactive: interface épurée et moderne qui s'adapte à toutes les tailles d'écran
  • Entièrement localisé: tous les textes de l'interface utilisateur, les libellés d'événements et les noms de grades/décorations respectent la langue que vous avez sélectionnée. Chaque carrière peut également s'afficher dans une langue différente si cela est configuré

Mode d'emploi

  1. Recherchez Career_Service_Record.exe dans le répertoire d'installation de Campaign Tracker
  2. Double-cliquez sur Career_Service_Record.exe pour lancer l'application (ou lancez-la depuis l'interface graphique du Control Center)
  3. Votre navigateur Web par défaut s'ouvrira automatiquement et affichera l'aperçu de votre carrière
  4. Cliquez sur n'importe quelle carrière pour afficher le dossier de service complet avec la chronologie, les statistiques et les débriefings
  5. Le serveur s'éteindra automatiquement après 60 secondes d'inactivité

Remarque: le Career Service Record se connecte au répertoire du jeu IL-2. S'il ne parvient pas à trouver le fichier cp.db du jeu, assurez-vous qu'IL-2 est bien installé et que vous avez commencé au moins une carrière dans le jeu.

  • Panneau de droite: liste de toutes les carrières, chacune affichant :
    • le nom, le pays et le grade du pilote
    • Chaîne des théâtres d'opérations (par exemple, « Bataille de Moscou → Stalingrad »)

  • Colonne centrale: statistiques de carrière — score PCP, répartition des victoires (aériennes, terrestres, véhicules), résultats des missions et utilisation des appareils
  • Colonne de droite: comptes rendus de mission avec détails des victimes par sortie, temps de vol et résultats
  • Bouton Retour: retour à l'aperçu de la carrière

Personnalisation des informations sur le pilote

Cliquez sur la photo du pilote ou sur n'importe quel champ modifiable pour personnaliser :

  • Photo du pilote: cliquez pour télécharger une nouvelle photo (formats JPG, PNG et BMP pris en charge)

  • Lieu de naissance: saisie libre
  • Pays de naissance: saisie libre
  • Toutes les modifications sont enregistrées automatiquement et conservées d'une session à l'autre

❓ FAQ

Pourquoi ma campagne personnalisée n'est-elle pas détectée / pourquoi les missions ne sont-elles pas détectées ?

R : Le tracker analyse les fichiers de mission pour en extraire les dates et les métadonnées. Pour vous assurer que votre campagne personnalisée est correctement détectée, suivez ces règles d'or :

⚠️ Important : fichiers de localisation en anglais requis pour la lecture

Le tracker ne lit que les fichiers de localisation en anglais (.eng briefings et info.locale=eng.txt) pour extraire les dates des missions et les informations sur la campagne. IL-2 stocke en interne la préférence linguistique de l'utilisateur, et nous n'avons aucun moyen de détecter la langue que vous utilisez dans le jeu. Par conséquent :

  • Chaque mission doit disposer d'un fichier de briefing .eng correspondant (par exemple, 01.eng pour la mission 01)
  • Votre dossier de campagne doit contenir un fichier info.locale=eng.txt pour la description de la campagne

Même si vous jouez dans une autre langue, ces fichiers en anglais doivent exister pour que le tracker fonctionne. Le tracker ne lira pas les fichiers .ger, .rus, .fra ou d'autres fichiers de langue pour l'extraction des dates.

ℹ️ Sortie multilingue

Lorsque vous réenregistrez des événements et des débriefings dans votre campagne, le tracker met automatiquement à jour tous les fichiers info.locale=*.txt existants. Chaque fichier est rédigé dans la langue correspondante :

  • info.locale=eng.txt → Contenu en anglais
  • info.locale=ger.txt → Contenu en allemand (Deutsch)
  • info.locale=fra.txt → Contenu en français (Français)
  • info.locale=spa.txt → Contenu en espagnol (Español)
  • info.locale=pol.txt → Contenu en polonais (Polski)
  • info.locale=rus.txt → Contenu en russe (Русский)
  • info.locale=chs.txt → Contenu en chinois (简体中文)

Voir Langues prises en charge pour plus de détails.

Nommage des fichiers de mission :

  • Utilisez des préfixes numériques pour l'ordre des missions : 01.Mission, 02.Mission, 03.Mission ou 1.Mission, 2.Mission, etc.
  • La dénomination basée sur la date fonctionne également : 1943-07-04.Mission, 1943-07-04a.Mission
  • Extensions prises en charge : .Mission, .mission, .msnbin

Détection de la date de la mission (dans les fichiers de briefing .eng ) : Le tracker recherche les informations de date dans l'ordre de priorité suivant :

  1. Date : champ dans le briefing (par ex., Date : 4 novembre 1943)
  2. Champ« Time: » pour l'heure de début de la mission (par exemple, Time: 09:45)
  3. Nom de fichier s'il contient une date (par exemple, 1943-07-04.Mission)

Formats de date pris en charge :

  • 4 novembre 1943 ou 4 novembre 1943
  • 4 novembre 1943 (sans virgule)
  • 04.11.1943 ou 11.04.1943 (JJ.MM.AAAA ou MM.JJ.AAAA)
  • 1943-07-04 (format ISO dans le nom de fichier)

Structure du dossier de campagne :

Chemin d'accès : IL-2 BoS\data\Campaigns\YourCampaignName\
    ├── info.locale=eng.txt    (obligatoire pour la lecture - description de la campagne)
    ├── info.locale=ger.txt    (facultatif - le tracker écrit ici le contenu en allemand)
    ├── info.locale=fra.txt    (facultatif - le tracker écrit ici le contenu en français)
    ├── info.locale=rus.txt    (facultatif - le tracker écrit ici le contenu en russe)
    ├── 01.Mission             (fichier de mission)
    ├── 01.eng                 (obligatoire - briefing en anglais avec date/heure)
    ├── 02.Mission
    ├── 02.eng                 (obligatoire - briefing en anglais avec date/heure)
    └── ...

Détection du pays : Le tracker détecte automatiquement votre pays/faction à partir de :

  1. Noms d'avions dans les fichiers de mission (par exemple, bf109 → Allemagne, spitfire → Grande-Bretagne)
  2. Noms d'unités contenant des identifiants de pays
  3. Vous pouvez définir/corriger cela manuellement dans l'interface graphique du Country Validator lors de la première exécution, ou l'ajuster manuellement plus tard dans le fichier stock_campaigns.yaml

Problèmes courants :

  • Fichier de briefing .eng manquant → les dates ne peuvent pas être extraites (la mission sera toujours suivie sous le nom « Mission 1 », « Mission 2 », etc., mais sans informations de date)
  • Fichier info.locale=eng.txt manquant → description de la campagne indisponible, le tracker ne peut pas lire les informations de la campagne
  • Format de date non standard dans le briefing → utilisez l'un des formats pris en charge ci-dessus
  • Caractères spéciaux dans le nom du dossier de campagne → évitez les trémas ou les symboles spéciaux
  • Campagnes de la Première Guerre mondiale (Flying Circus) → exclues par défaut (voir la section Détection et exclusion de la Première Guerre mondiale)

Q : Puis-je exécuter plusieurs instances du tracker ?

R : Non. Une seule instance doit surveiller vos campagnes à la fois.

Q : Le tracker modifie-t-il mon installation d'IL-2 ?

R : Le tracker ne modifie que :

  • Fichiers info.locale=eng.txt de la campagne (ajoute la section Événements)
  • Crée des fichiers de sauvegarde dans le dossier usersave

Il ne modifie aucun fichier exécutable ni aucun fichier système du jeu.

Q : Cela fonctionnera-t-il avec les mods ?

R : Oui, à condition que le mod utilise une structure de campagne standard. Les campagnes personnalisées sont automatiquement détectées lors de la configuration initiale.

Q : Puis-je modifier manuellement la configuration ?

R : Oui, mais nous recommandons d'utiliser le Gestionnaire de paramètres (IL2_Settings_Manager.exe) pour la plupart des modifications. Il offre une interface conviviale et gère automatiquement la régénération lorsque cela est nécessaire.

Pour une personnalisation avancée, le fichier campaign_progress_config.yaml peut être modifié manuellement pour :

  • Ajuste les seuils de score de promotion
  • Modifie les critères d'attribution des récompenses
  • Ajoute des récompenses personnalisées
  • Modifie les facteurs d'échelle des classements

⚠️ Créez toujours une sauvegarde avant de modifier manuellement les fichiers de configuration.

Q : Comment tout réinitialiser ?

R : Supprimez ces fichiers et redémarrez le tracker :

  • campaign_mission_dates.json
  • campaign_popups_seen.json
  • campaigns_decoded.json
  • campaign_events.json

Q : Le mode multijoueur est-il pris en charge ?

R : Le tracker est conçu pour les campagnes en mode solo. Les missions multijoueur ne génèrent pas la même structure de données de sauvegarde.

Q : Pourquoi dois-je redémarrer IL-2 pour voir les nouveaux événements ?

R : IL-2 charge la description de la campagne (info.locale=eng.txt) au démarrage du jeu et la met en cache en mémoire. Les modifications apportées par le tracker sont enregistrées dans le fichier, mais n'apparaîtront pas dans le jeu tant que vous n'aurez pas redémarré IL-2. Cependant, vous verrez toujours s'afficher immédiatement des fenêtres contextuelles lorsque vous obtiendrez des promotions ou des récompenses.

Q : Que se passe-t-il si je supprime manuellement un fichier de sauvegarde ?

R : L'index de sauvegarde (campaignsstates_hash_index.json) continuera de le référencer, mais l'interface graphique de restauration ignorera toute sauvegarde pour laquelle le fichier de sauvegarde proprement dit est manquant.

Q : Puis-je utiliser le tracker avec Flying Circus (Première Guerre mondiale) ?

R : Les campagnes Flying Circus sont détectées et exclues par défaut. Le tracker est conçu pour les campagnes de la Seconde Guerre mondiale et ne comprend pas les grades ni les récompenses de la Première Guerre mondiale. Vous pouvez contrôler les exclusions lors de l'étape de validation du pays (case à cocher « ignorer » pour la Première Guerre mondiale), mais les campagnes de la Première Guerre mondiale n'auront pas de grades ni de récompenses historiquement exacts.

Q : Puis-je utiliser le tracker avec le générateur de campagne de Pat Wilson (PWCG) ?

R : Non, ce tracker ne fonctionne PAS avec PWCG, mais n'interfère PAS non plus avec celui-ci
